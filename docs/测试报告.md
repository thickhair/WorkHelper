## 1. 概述

本文档记录 Workbench V1.0 的测试执行情况，包括单元测试、集成测试与系统级验证的结果，以及开发过程中发现并处理的缺陷与工程化问题。测试目标是验证功能需求（《需求规格说明书》第 2 章）与非功能需求（第 3 章）的实现质量，并给出能否通过验收标准（第 6 章）的结论。

测试采用分层策略：

- 单元测试：覆盖主/渲染进程共享的纯函数逻辑（`src/shared/logic.ts`、`src/shared/calendar.ts`、`src/shared/anniversaries.ts`、`src/shared/reader.ts` 等）。
- 存储层集成测试：在 Node 环境下以临时目录作为数据目录，验证数据库迁移（user_version=7，含 V7 阅读书库与书签表）、种子数据与各领域服务的增删改查、统计计算（`src/main/db`、`src/main/services`）。
- 渲染层集成测试：以 jsdom 环境挂载真实 Vue 组件，mock `window.api`，验证数据加载、关键元素渲染与交互回调。
- 系统级验证：开发态 UI 自动截图、打包产物校验、打包版实机运行验证。
