## 2. 产品简介

### 2.1 产品定位

个人工作台 WorkHelper 是一款面向个人的 Windows 桌面效率工具，集「任务管理、日程安排、习惯打卡、笔记记录、数据统计」于一体。应用界面采用绿色主题、白色圆角卡片与进度环设计，全部功能离线可用，数据仅存储在本机 SQLite 数据库中，不上传网络。

### 2.2 核心价值

1. 一站式规划：把日程、待办、重要事项、习惯打卡集中在「每日计划」页管理。
2. 分类沉淀：为学习与生活主题（运动、英语、剪辑、读书等）建立独立空间，记录投入时长与笔记。
3. 数据回顾：通过统计图表与工作复盘沉淀每一天的积累，形成正向反馈。
4. 隐私安全：全部数据本地存储，支持手动备份与恢复，便于迁移到新电脑。

### 2.3 功能一览表

| 模块 | 主要能力 |
| --- | --- |
| 首页 | 问候卡片、四张统计卡片、今日日程、今日待办、近 7 天完成趋势、下一步行动、快捷入口 |
| 每日计划 | 日期切换、日程增删改、待办勾选、重要事项优先级、习惯打卡、专注计时 |
| 功能广场 | 分组展示全部功能，支持添加到侧边栏 / 移除 / 一键恢复默认 |
| 专注空间 | 番茄式专注计时（15/25/45/60 分钟），记录专注时长与最近记录 |
| 分类模块（9 个） | 模块目标、投入记录（时长/备注）、模块笔记 |
| 新闻资讯 | 资讯增删改、来源与标签、收藏、搜索、打开链接 |
| 工作复盘 | 按天记录今日完成、问题与反思、明日计划、今日心情，支持删除 |
| 数据统计 | 累计完成任务、累计打卡次数、连续打卡天数、累计专注时长、趋势图与排行榜 |
| 设置 | 外观主题（6 套配色即时切换）、昵称、导出备份、导入恢复、打开数据目录、关于信息 |

分类模块共 9 个：减肥运动、英语学习、剪辑学习、播客精选、表达能力、读书推荐、妆容穿搭、爆款二创、AI学习。

## 4. 安装与卸载

### 4.1 安装包信息

| 项目 | 内容 |
| --- | --- |
| 文件名 | WorkHelper-1.0.0-Setup.exe |
| 位置 | 交付目录 `dist/` |
| 架构 | x64 |
| 大小 | 约 115 MB |
| 安装方式 | NSIS 安装向导（中文界面） |
| 安装范围 | 默认按当前用户安装，无需管理员权限 |

### 4.2 安装步骤

1. 打开交付目录 `dist/`，双击安装包 `WorkHelper-1.0.0-Setup.exe`。
2. 如系统弹出「用户账户控制」或 SmartScreen 提示，选择允许运行（详见第 9 章 FAQ）。
3. 在「安装选项」页选择安装范围（默认「仅为我安装」，也可选择为所有用户安装），点击「下一步」。
4. 在「选定安装位置」页确认安装目录：默认安装到当前用户目录；点击「浏览」或直接修改路径后，安装器会自动在所选目录下追加 `WorkHelper` 子文件夹（例如选择 `D:\app`，最终安装到 `D:\app\WorkHelper`），并在输入框中同步显示最终安装路径。
5. 依次点击「安装」开始安装，等待进度完成。
6. 点击「完成」结束安装。此时桌面会出现名为「个人工作台」的快捷方式，开始菜单中也会创建对应快捷方式。
7. 双击桌面「个人工作台」快捷方式启动应用。

### 4.3 卸载步骤

1. 打开「设置」→「应用」→「已安装的应用」（或通过控制面板的「程序和功能」）。
2. 在列表中找到「个人工作台 WorkHelper」。
3. 点击「卸载」，在卸载向导中确认卸载。
4. 按提示完成卸载。

### 4.4 数据说明

1. 应用数据保存在本机数据目录的 `workhelper.db` 文件中（详见第 8 章），不在安装目录内。
2. 卸载应用不会自动删除用户数据。若今后要重装或彻底清理，卸载前建议先在应用内备份数据；确认不再需要数据时，再手动删除数据目录中的文件。
3. 建议在卸载、重装或清理前，先通过「设置」中的「导出备份」保存一份 JSON 备份。

## 5. 快速上手

### 5.1 首次启动会看到什么

1. 启动后进入「首页」，顶部为问候卡片，显示当前时间对应的问候语与昵称。
2. 首页依次展示四张统计卡片（今日任务、习惯打卡、今日进度、今日状态）、今日日程、今日待办、近 7 天完成趋势与「下一步行动」。
3. 左侧为绿色侧边栏，包含全部功能入口；首次使用时各列表为空，会显示引导文案，例如今日日程区域显示「今天还没有安排日程」。

### 5.2 五分钟上手流程

1. 点击左侧「每日计划」进入计划页。
2. 在「今日日程」卡片点击「添加日程」，在弹窗中填写「标题」与「时间」，点击「保存」，创建一条日程。
3. 在日程行右侧点击圆形勾选按钮，将日程标记为完成（再次点击可取消完成）。
4. 在「今日待办」卡片点击「添加待办」，填写「标题」与开始/结束「时间」，点击「保存」。
5. 在「习惯打卡」卡片点击「管理习惯」，点击「新增习惯」，填写「习惯名称」、选择「图标」与「每日目标次数」，点击「保存」，再点击「完成」关闭管理弹窗。
6. 返回列表，点击习惯进度环进行打卡（打卡后右上角出现可撤销的「−」按钮）。
7. 点击左侧「数据统计」，查看累计完成任务、习惯打卡、连续打卡天数、累计专注时长以及图表。
8. 点击左侧「工作复盘」，点击「写今日复盘」，填写今日内容并「保存复盘」。

## 6. 界面总览

### 6.1 窗口结构

应用采用无边框窗口，整体分为三个区域：

1. 左侧侧边栏：绿色渐变背景，自上而下为 Logo 区与导航菜单，底部显示「V1.0 · 数据本地存储」。Logo 区显示「我的工作台」与「WorkHelper」。
2. 顶部窗口控制条：位于内容区上方，右侧为窗口控制按钮，其余区域可拖拽移动窗口，双击该区域可在最大化与还原之间切换。
3. 内容区：显示当前选中的页面，垂直滚动，页面切换带淡入淡出过渡。

### 6.2 侧边栏菜单

侧边栏默认自上而下依次为（可在「功能广场」中自由增删）：

1. 首页（固定项，不可移除）
2. 每日计划
3. 减肥运动
4. 英语学习
5. 剪辑学习
6. 播客精选
7. 表达能力
8. 读书推荐
9. 妆容穿搭
10. 爆款二创
11. AI学习
12. 新闻资讯
13. 工作复盘
14. 数据统计
15. 功能广场（固定项，不可移除）
16. 设置（固定项，不可移除）

其中「专注空间」为默认未添加的可选功能，可在功能广场中点击「添加」后显示。

自定义侧边栏的方式：

1. 添加功能：进入「功能广场」，在目标功能卡片上点击「添加」，该功能立即出现在侧边栏。
2. 移除功能：将鼠标移到侧边栏的普通菜单项上，右侧会出现「×」按钮，点击即可移除；也可在功能广场中点击「移除」。
3. 恢复默认：在功能广场顶部点击「恢复默认」，侧边栏回到默认配置。
4. 固定项：「首页」「功能广场」「设置」始终显示，不可移除；移除当前正在浏览的功能时，会自动回到首页。

点击任一菜单项即可切换到对应页面，当前项以浅色胶囊高亮显示。菜单项较多时侧边栏可滚动。

### 6.3 窗口控制按钮

内容区右上角共有三个按钮，从左到右为：

1. 「最小化」：将窗口最小化到任务栏。
2. 「最大化」/「还原」：在最大化与还原之间切换，按钮图标随窗口状态自动变化。
3. 「关闭」：关闭应用窗口。鼠标悬停时按钮变为红色。

此外，将鼠标移到窗口顶部拖拽区域按住可移动窗口，双击该区域可快速切换最大化。

### 6.4 滚动与响应式行为

1. 内容区自动垂直滚动，内容较长时使用鼠标滚轮查看。
2. 窗口变窄时，多列内容会自动重排为单列（如首页统计卡片、图表区等），以保证在较小窗口下仍可阅读。

### 6.5 操作反馈

操作成功或失败时，窗口顶部居中会短暂弹出提示条（Toast），约 2.4 秒后自动消失。成功为绿色提示（如「已保存」「已删除」），失败为红色提示；部分信息为中性提示。删除等危险操作会先弹出确认弹窗，需再次确认。

## 7. 各模块操作指南

### 7.1 首页

功能说明：首页是仪表盘，汇总今日概况，并提供常用入口。

页面元素：

1. 问候卡片：根据当前时间显示问候语（早上好/下午好/晚上好等），显示昵称、当天日期、今日进度百分比与状态，以及三个快捷入口。
2. 统计卡片：今日任务（已完成/总数）、习惯打卡（已完成/总数）、今日进度（百分比）、今日状态（如「等待计划」或状态文案）。
3. 今日日程：显示前 5 条日程，可勾选完成，点击「查看全部」跳转到「每日计划」。
4. 今日待办：显示前 5 条待办，可勾选完成，点击「查看全部」跳转到「每日计划」。
5. 近 7 天完成趋势：迷你柱状图，深色为已完成。
6. 下一步行动：显示即将开始的日程，点击「去开始」跳转到「每日计划」；若今日日程全部完成，显示「今日计划已全部完成」。

操作步骤：

1. 在今日日程或今日待办中，点击条目左侧/右侧的圆形勾选按钮即可标记完成，再次点击取消。
2. 点击问候卡片中的「每日计划」「数据统计」「工作复盘」快捷入口，可快速跳转到对应页面。

空状态提示：今日日程为空时显示「今天还没有安排日程」；今日待办为空时显示「暂无待办事项」。

### 7.2 每日计划

#### 7.2.1 日期切换

功能说明：所有卡片随所选日期联动，可查看与规划任意一天。

操作步骤：

1. 页面右上角显示当前日期与星期。
2. 点击「前一天」按钮查看前一日，点击「后一天」按钮查看后一日。
3. 当所选日期不是今天时，会出现「回到今天」按钮，点击即可返回今日。

#### 7.2.2 日程

功能说明：日程是一天中带固定时间点的安排。

操作步骤（新增）：

1. 在「今日日程」卡片点击「添加日程」。
2. 在弹窗「标题」中填写内容，在「时间」中选择时间点，可选填「备注描述」。
3. 点击「保存」。保存成功后页面右上角提示「已保存」。

操作步骤（编辑/删除/完成）：

1. 将鼠标移到日程行上，行右侧会出现「编辑」「删除」按钮。
2. 点击「编辑」修改内容后「保存」；点击「删除」后，在确认弹窗中点击「确认删除」。
3. 点击行尾的圆形勾选按钮标记完成，已完成日程标题显示删除线，再次点击可取消。

字段含义：「标题」为日程名称；「时间」为日程开始时间点；「备注描述」为选填补充说明。

空状态提示：无日程时显示「还没有日程安排，点击「添加日程」开始规划」。

#### 7.2.3 待办

功能说明：待办是当日需要完成的事项，可关联一个时间段。

操作步骤：

1. 在「今日待办」卡片点击「添加待办」。
2. 填写「标题」，设置「开始时间」与「结束时间」。
3. 点击「保存」。
4. 点击待办行左侧的圆形勾选按钮标记完成（标题显示删除线），再次点击取消。
5. 鼠标悬停到行上，点击「编辑」或「删除」进行修改或删除；删除需在确认弹窗中点击「确认删除」。

字段含义：「标题」为待办内容；「开始时间」「结束时间」为待办时间段。

空状态提示：无待办时显示「暂无待办事项」；卡片标题右侧显示「N 项」总数。

#### 7.2.4 重要事项

功能说明：重要事项是当日重点，带高/中/低优先级色标，方便排定先后。

操作步骤：

1. 在「重要事项」卡片点击「添加」。
2. 填写「标题」，设置「开始时间」「结束时间」，在「优先级」中选择「高优先级」「中优先级」或「低优先级」。
3. 点击「保存」。
4. 点击行尾的圆形勾选按钮标记完成；鼠标悬停后可用「编辑」「删除」修改或删除。

字段含义：优先级色标含义为——高优先级（红色）、中优先级（黄色）、低优先级（绿色）。将鼠标悬停在圆点上可查看「高优先级」等提示。

空状态提示：无重要事项时显示「暂无重要事项」；卡片标题右侧显示「N 项」总数。

#### 7.2.5 习惯打卡

功能说明：习惯是需按天重复完成的目标，用进度环展示「已完成/目标」。

操作步骤（打卡）：

1. 在「习惯打卡」卡片点击某习惯的进度圆环，即可打卡一次（计数 +1）。
2. 打卡后习惯项右上角出现「−」按钮，点击可撤销一次打卡（计数 −1）。

操作步骤（管理习惯）：

1. 点击「管理习惯」打开管理弹窗，列表中显示每个习惯的图标、名称与「目标 N 次/天」。
2. 点击「新增习惯」，填写「习惯名称」，在「图标」中选择一个表情图标，设置「每日目标次数」（有效范围 1 至 20），点击「保存」。
3. 在管理列表点击某习惯的「编辑」可修改，点击「删除」删除（确认提示为「确定删除习惯「名称」吗？历史打卡记录将一并删除。」）；删除需点击「确认删除」。
4. 完成后点击「完成」关闭管理弹窗。

字段含义：「习惯名称」为目标名称；「图标」为进度环中心显示的表情；「每日目标次数」为每天需完成的目标次数。

空状态提示：无习惯时显示「还没有习惯，点击「管理习惯」添加」。

#### 7.2.6 专注计时

功能说明：针对当天「下一个任务」进行倒计时专注，完成后自动标记对应日程为已完成并记录专注时长。

操作步骤：

1. 在「下一个任务」卡片确认推荐的任务，点击「开始」。
2. 窗口右下角出现悬浮的专注卡片「专注中」，显示任务名称、倒计时（默认 30 分钟）、进度条。
3. 倒计时结束后，点击「完成」结束专注（记录实际专注分钟数，至少 1 分钟），此时会提示「已完成「任务名称」，专注 N 分钟」，并将该日程标记为完成。
4. 中途如需放弃，点击「放弃」或卡片右上角的「关闭」按钮，放弃不会记录专注时长。

注意事项：若当天日程已全部完成，在「下一个任务」卡片点击「开始」会提示「今日日程已全部完成，休息一下吧」。专注卡片位于窗口右下角，不会随页面切换而消失。

### 7.3 分类学习模块

功能说明：9 个分类模块共用同一套工作区，用于记录投入时长、沉淀笔记，并展示模块目标与累计概览。

模块列表：减肥运动、英语学习、剪辑学习、播客精选、表达能力、读书推荐、妆容穿搭、爆款二创、AI学习。

页面元素：

1. 页头：显示模块名称与图标，以及模块目标。
2. 概览卡片：累计投入次数、累计投入时长、最近记录日期。

## 8. 数据管理

### 8.1 数据存储位置

1. 数据库文件位于本机数据目录：`%APPDATA%\WorkHelper\data\workhelper.db`（WAL 模式）。
2. 在「设置」→「数据安全」中点击「打开目录」可直接定位该目录。
3. 应用不联网上传数据，所有记录均保存在本机。

### 8.2 备份（导出）

操作步骤：

1. 进入「设置」→「数据安全」。
2. 点击「导出备份」。
3. 在系统保存对话框中选择保存位置与文件名，确认保存。
4. 保存成功提示「备份已导出」。

影响范围：导出为 JSON 文件，包含全部业务数据（日程、待办、习惯及打卡、重要事项、分类记录与笔记、资讯、复盘、专注记录、设置等）。导出操作不会修改现有数据。

### 8.3 恢复（导入）

操作步骤：

1. 进入「设置」→「数据安全」。
2. 点击「导入恢复」。
3. 在确认弹窗中阅读提示后点击「继续导入」。
4. 选择此前导出的 JSON 备份文件，确认导入。
5. 导入成功后提示「数据已恢复，正在刷新…」，界面自动刷新。

影响范围：导入会用备份文件覆盖本机现有全部数据，且无法撤销。若备份文件格式不正确，会提示「备份文件格式不正确，无法恢复」。恢复前建议先导出一份当前数据作为保险。

### 8.4 导出为 JSON（迁移/留档）

导出数据即第 8.2 节的 JSON 备份文件，可用于迁移到新电脑或长期留档。

### 8.5 清空数据

本版本「设置」中未提供一键「清空数据」的按钮。如需彻底重置数据，建议按以下步骤稳妥处理：

1. 先在「设置」中点击「导出备份」，保存一份备份以防误操作。
2. 完全退出应用（点击窗口右上角「关闭」）。
3. 在「设置」→「数据安全」点击「打开目录」（或手动打开 `%APPDATA%\WorkHelper\data`），删除其中的 `workhelper.db` 文件（如存在同名的 `-wal`、`-shm` 文件，一并删除）。
4. 重新启动应用，将自动创建全新的空数据库。

影响范围：删除数据库文件后原有全部记录不可恢复，请务必先完成备份。卸载应用本身不会自动删除该文件，需要手动清理。

### 8.6 迁移到新电脑

操作步骤：

1. 在旧电脑上进入「设置」→「数据安全」，点击「导出备份」，得到 JSON 备份文件。
2. 将 JSON 备份文件复制到新电脑。
3. 在新电脑安装并启动 WorkHelper。
4. 进入「设置」→「数据安全」，点击「导入恢复」，按提示选择该 JSON 文件并「继续导入」。
5. 导入完成后界面自动刷新，数据即迁移完成。

## 9. 常见问题 FAQ

1. 我的数据存在哪里？
   答：保存在本机数据目录的 `workhelper.db` 文件中，路径为 `%APPDATA%\WorkHelper\data\workhelper.db`（WAL 模式）。可在「设置」→「数据安全」点击「打开目录」查看。

2. WorkHelper 会联网吗？会上传我的数据吗？
   答：不会。应用全部功能离线可用，数据只保存在本机；仅当你主动点击资讯的「打开链接」时，才会用系统默认浏览器打开对应网址。

3. 如何把数据迁移到另一台电脑？
   答：先在原电脑「设置」中「导出备份」，把 JSON 文件复制到新电脑，在新电脑用「导入恢复」载入即可（详见第 8.6 节）。

4. 误删了日程/待办/复盘等记录，能恢复吗？
   答：应用内的删除是即时的，没有回收站。若有较新的 JSON 备份，可通过「导入恢复」找回备份时的状态（会覆盖当前全部数据）；若没有备份则无法恢复。建议定期备份。

5. 安装时被 SmartScreen 或杀毒软件拦截/报毒怎么办？
   答：安装包未做代码签名，Windows 可能提示「Windows 已保护你的电脑」。此时点击「更多信息」→「仍要运行」即可继续；如被第三方杀毒软件拦截，可在确认安装包来源可靠后将其加入信任/白名单。若仍有顾虑，请核对安装包名称与大小是否与官方交付一致。

6. 习惯的「连续打卡天数」是怎么算的？
   答：「连续打卡天数」统计的是从最近有打卡记录的日期起、向前连续有打卡的天数；若中间某天没有任何打卡，连续计数会中断。

7. 数据统计里的口径分别是什么？
   答：「累计完成任务」为所有日期已完成任务数合计；「累计习惯打卡」为所有打卡次数合计；「连续打卡天数」为上述连续天数；「累计专注时长」为专注计时完成所记录的总分钟数。趋势图统计最近 7 天，习惯完成率为当日打卡次数与目标次数之比。

8. 为什么某天多填/重复保存复盘不会新增多条？
   答：复盘以日期为唯一标识，同一天重复「保存复盘」会覆盖该日内容，不会产生重复记录。

9. 数据清空/删库后能撤销吗？
   答：不能。删除 `workhelper.db` 属于不可逆操作，且应用内「导入恢复」只能恢复备份文件中的内容。执行前请务必先「导出备份」。

10. 卸载应用会删除我的数据吗？
    答：不会自动删除。数据文件位于独立的数据目录，卸载程序不会移除它。如需彻底清理，请在卸载前先备份，卸载后手动删除数据目录中的文件。

## 10. 开发者与高级用法

本章面向希望自行运行或打包源码的开发者。

### 10.1 npm 命令一览

| 命令 | 说明 |
| --- | --- |
| `npm install` | 安装依赖 |
| `npm run dev` | 启动开发模式（带热更新） |
| `npm run start` | 预览已构建产物 |
| `npm run typecheck` | 类型检查（主进程 + 渲染进程） |
| `npm test` | 运行单元测试 |
| `npm run test:watch` | 以监听模式运行测试 |
| `npm run build` | 构建生产代码 |
| `npm run dist` | 构建并生成 Windows NSIS 安装包 |

打包产物位于 `dist/`，安装包名为 `WorkHelper-1.0.0-Setup.exe`。运行环境要求 Node.js 18 及以上。

### 10.2 便携模式（WORKHELPER_DATA_DIR）

1. 应用支持通过环境变量 `WORKHELPER_DATA_DIR` 指定自定义数据目录，用于开发调试或便携使用。
2. 当设置了该变量时，应用的用户数据目录会被指向该路径，数据库文件位于其下的 `data/` 子目录中，从而实现「数据与程序放在一起」的便携模式。

### 10.3 技术栈（供参考）

Electron 44（无边框窗口）+ Vue 3 + TypeScript + Pinia + Vue Router + SQLite（优先 better-sqlite3，自动回退 Node 内置 node:sqlite），打包使用 electron-builder。

## 11. 快捷键与技巧

### 11.1 键盘操作说明

本版本以鼠标操作为主，未内置全局键盘快捷键。以下键盘交互与系统窗口行为仍然可用：

1. 在弹窗表单中，光标位于「标题」等输入框时按回车可直接提交保存（例如日程、待办、重要事项、投资记录、资讯、习惯、昵称等输入框）。
2. 双击窗口顶部拖拽区域可切换最大化/还原。

### 11.2 鼠标技巧

1. 列表行（日程、待办、重要事项、投入记录、笔记、资讯、复盘）的「编辑」「删除」按钮在鼠标悬停时才会显示，将鼠标移到该行即可看到。
2. 在习惯打卡区，点击进度环打卡，悬停习惯项可看到右上角的「−」撤销按钮。
3. 点击圆形勾选按钮可快速切换完成状态，无需进入编辑弹窗。
4. 专注计时卡片固定在窗口右下角，切换页面时不会消失。

### 11.3 使用建议

1. 每天先到「每日计划」安排日程与待办，再用首页概览跟踪进度。
2. 习惯目标次数不宜设置过高，保持可持续的打卡节奏更利于形成连续天数。
3. 坚持写「工作复盘」，并结合「数据统计」观察趋势，定期导出备份以防数据丢失。
