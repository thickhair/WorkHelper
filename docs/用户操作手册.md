## 2. 产品简介

### 2.1 产品定位

个人工作台 Workbench 是一款面向个人的 Windows 桌面效率工具，集「任务管理、日程安排、习惯打卡、心情记录、资产管理」于一体。应用界面采用绿色主题、白色圆角卡片与进度环设计，全部功能离线可用，数据仅存储在本机 SQLite 数据库中，不上传网络。

### 2.2 核心价值

1. 一站式规划：把日程、待办、重要事项、习惯打卡集中在「每日计划」页管理。
2. 资产管家：集中管理各平台账户余额与日常收支，配合攒钱计划追踪每一个储蓄目标。
3. 日历总览：公历农历、节假日、天气、生日、倒数日与纪念日集中一屏，重要日子不再错过。
4. 隐私安全：全部数据本地存储，支持手动备份与恢复，便于迁移到新电脑。

### 2.3 功能一览表

| 模块 | 主要能力 |
| --- | --- |
| 首页 | 问候卡片、四张统计卡片、今日日程、今日待办、近 7 天完成趋势、下一步行动、心情打卡、生日提醒、资产概览（添加「资产」后显示）、快捷入口 |
| 每日计划 | 日期切换、日程增删改、待办勾选、重要事项优先级、习惯打卡、专注计时 |
| 日历 | 月视图（公历 / 农历 / 节气 / 传统节日 / 法定节假日休班、日程、生日、倒数日 / 纪念日与每日心情标记）、右键日期快捷添加、当日详情、生日管理、生日提醒、倒数日与纪念日管理、未来一周天气、每日心情记录 |
| 功能广场 | 网格展示可配置功能（当前为「资产」1 项，实用工具分组），支持添加到侧边栏 / 移除 / 一键恢复默认（首页、每日计划、日历、功能广场为固定项） |
| 资产 | 账户管理（12 个平台）、收支记账（收入 7 类 / 支出 9 类）、概览卡片金额可隐藏、统计图表、攒钱计划与想买、首页资产概览联动 |
| 设置 | 入口位于窗口右上角：外观主题（6 套配色即时切换）、昵称、导出备份、导入恢复、打开数据目录、更改数据存储位置、关于信息 |

2. 安装包为 x64 架构，不支持 32 位系统。

## 4. 安装与卸载

### 4.1 安装包信息

| 项目 | 内容 |
| --- | --- |
| 文件名 | Workbench-1.0.0-Setup.exe |
| 位置 | 交付目录 `dist/` |
| 架构 | x64 |
| 大小 | 约 115 MB |
| 安装方式 | NSIS 安装向导（中文界面） |
| 安装范围 | 默认按当前用户安装，无需管理员权限 |

### 4.2 安装步骤

1. 打开交付目录 `dist/`，双击安装包 `Workbench-1.0.0-Setup.exe`。
2. 如系统弹出「用户账户控制」或 SmartScreen 提示，选择允许运行（详见第 9 章 FAQ）。
3. 在「安装选项」页选择安装范围（默认「仅为我安装」，也可选择为所有用户安装），点击「下一步」。
4. 在「选定安装位置」页确认安装目录：默认安装到当前用户目录；点击「浏览」或直接修改路径后，安装器会自动在所选目录下追加 `Workbench` 子文件夹（例如选择 `D:\app`，最终安装到 `D:\app\Workbench`），并在输入框中同步显示最终安装路径。
5. 依次点击「安装」开始安装，等待进度完成。
6. 点击「完成」结束安装。此时桌面会出现名为「个人工作台」的快捷方式，开始菜单中也会创建对应快捷方式。
7. 双击桌面「个人工作台」快捷方式启动应用。

### 4.3 卸载步骤

1. 打开「设置」→「应用」→「已安装的应用」（或通过控制面板的「程序和功能」）。
2. 在列表中找到「个人工作台 Workbench」。
3. 点击「卸载」，在卸载向导中确认卸载。
4. 按提示完成卸载。

### 4.4 数据说明

1. 应用数据保存在本机数据目录的 `workbench.db` 文件中（详见第 8 章），不在安装目录内；可在「设置」→「数据安全」中更改其存放位置。
2. 卸载应用不会自动删除用户数据。若今后要重装或彻底清理，卸载前建议先在应用内备份数据；确认不再需要数据时，再手动删除数据目录中的文件。
3. 建议在卸载、重装或清理前，先通过「设置」中的「导出备份」保存一份 JSON 备份。

## 5. 快速上手

### 5.1 首次启动会看到什么

1. 启动后进入「首页」，顶部为问候卡片，显示当前时间对应的问候语与昵称。
2. 首页依次展示四张统计卡片（今日任务、习惯打卡、今日进度、今日状态）、今日日程、今日待办、近 7 天完成趋势与「下一步行动」。
3. 左侧为绿色侧边栏，固定显示「首页 / 每日计划 / 日历 / 功能广场」，其余功能可在其中添加；首次使用时各列表为空，会显示引导文案，例如今日日程区域显示「今天还没有安排日程」。

### 5.2 五分钟上手流程

1. 点击左侧「每日计划」进入计划页。
2. 在「今日日程」卡片点击「添加日程」，在弹窗中填写「标题」与「时间」，点击「保存」，创建一条日程。
3. 在日程行右侧点击圆形勾选按钮，将日程标记为完成（再次点击可取消完成）。
4. 在「今日待办」卡片点击「添加待办」，填写「标题」与开始/结束「时间」，点击「保存」。
5. 在「习惯打卡」卡片点击「管理习惯」，点击「新增习惯」，填写「习惯名称」、选择「图标」与「每日目标次数」，点击「保存」，再点击「完成」关闭管理弹窗。
6. 返回列表，点击习惯进度环进行打卡（打卡后右上角出现可撤销的「−」按钮）。
7. 点击左侧「日历」，在月视图中右键点击任意日期，可快速添加生日、日程、倒数日或纪念日（也可点击首页或「每日计划」右上角的日期胶囊随时打开日历，操作详见第 7.4 节）。
8. 点击左侧「功能广场」，将「资产」添加到侧边栏，进入后创建第一个账户并记下第一笔收支。

## 6. 界面总览

### 6.1 窗口结构

应用采用无边框窗口，整体分为三个区域：

1. 左侧侧边栏：绿色渐变背景，自上而下为 Logo 区与导航菜单，底部显示「V1.0 · 数据本地存储」。Logo 区显示「我的工作台」与「Workbench」。
2. 顶部窗口控制条：位于内容区上方，右侧为「设置」入口与窗口控制按钮，其余区域可拖拽移动窗口，双击该区域可在最大化与还原之间切换。
3. 内容区：显示当前选中的页面，垂直滚动，页面切换带淡入淡出过渡。

### 6.2 侧边栏菜单

侧边栏顶部固定显示四项功能（始终可见、不可移除）：

1. 首页
2. 每日计划
3. 日历
4. 功能广场

其余功能（当前为「资产」1 项）可在「功能广场」中按需添加，添加后显示在固定项下方；「设置」不在侧边栏中，入口位于窗口右上角（见 6.3）。

自定义侧边栏的方式：

1. 添加功能：进入「功能广场」，在目标功能磁贴上点击「添加」，该功能立即出现在侧边栏。
2. 移除功能：将鼠标移到侧边栏中可配置功能的菜单项上，右侧会出现「×」按钮，点击即可移除；也可在功能广场中点击「移除」。固定的四项不显示「×」按钮，不可移除。
3. 恢复默认：在功能广场顶部点击「恢复默认」，侧边栏回到默认配置（仅保留四个固定功能）。
4. 设置入口：点击窗口右上角的齿轮按钮即可打开设置页，无需添加到侧边栏。
5. 日期入口：「日历」已固定显示在侧边栏，点击首页或「每日计划」右上角的日期胶囊也可随时打开日历页。
6. 移除当前正在浏览的可配置功能时，会自动跳转到侧边栏中的第一个功能（首页）。
7. 窗口较窄时（宽度不超过 860px），侧边栏自动收起为图标模式，鼠标悬停可查看功能名称。

点击任一菜单项即可切换到对应页面，当前项以浅色胶囊高亮显示。菜单项较多时侧边栏可滚动。

### 6.3 窗口控制按钮

内容区右上角共有四个按钮，从左到右为：

1. 「设置」：齿轮图标，点击打开设置页；当前处于设置页时按钮高亮。
2. 「最小化」：将窗口最小化到任务栏。
3. 「最大化」/「还原」：在最大化与还原之间切换，按钮图标随窗口状态自动变化。
4. 「关闭」：关闭应用窗口。鼠标悬停时按钮变为红色。

此外，将鼠标移到窗口顶部拖拽区域按住可移动窗口，双击该区域可快速切换最大化。

### 6.4 滚动与响应式行为

1. 内容区自动垂直滚动，内容较长时使用鼠标滚轮查看。
2. 窗口变窄时，多列内容会自动重排为单列（如首页统计卡片、图表区等），以保证在较小窗口下仍可阅读。

### 6.5 操作反馈

操作成功或失败时，窗口顶部居中会短暂弹出提示条（Toast），约 2.4 秒后自动消失。成功为绿色提示（如「已保存」「已删除」），失败为红色提示；部分信息为中性提示。删除等危险操作会先弹出确认弹窗，需再次确认。

## 7. 各模块操作指南

### 7.1 首页

功能说明：首页是仪表盘，汇总今日概况，并提供常用入口。

页面元素：

1. 问候卡片：根据当前时间显示问候语（早上好/下午好/晚上好等），显示昵称、当天日期、今日进度百分比与状态，以及「每日计划」「资产」两个快捷入口。
2. 统计卡片：今日任务（已完成/总数）、习惯打卡（已完成/总数）、今日进度（百分比）、今日状态（如「等待计划」或状态文案）；四张卡片整体可点击（悬停时上浮，鼠标指针为手型），点击跳转到「每日计划」查看对应详情。
3. 今日日程：显示前 5 条日程，可勾选完成，点击「查看全部」跳转到「每日计划」。
4. 今日待办：显示前 5 条待办，可勾选完成，点击「查看全部」跳转到「每日计划」。
5. 近 7 天完成趋势：迷你柱状图，深色为已完成。
6. 下一步行动：显示即将开始的日程，点击「去开始」跳转到「每日计划」；若今日日程全部完成，显示「今日计划已全部完成」。
7. 心情打卡：位于右侧栏第一张卡片，提供 5 档心情按钮（糟糕 / 低落 / 一般 / 不错 / 开心），点击即可记录当天心情；标题右侧显示打卡状态——未打卡时显示「今天还没打卡」，打卡后显示「已打卡 · 连续打卡 N 天」（连续天数从今天往前回溯统计，断档后重新计数），下方提示「每天点一下打卡记录心情，可在日历中回看与补记」。
8. 资产概览：当「资产」已添加到侧边栏时显示，包含总资产、本月收入、本月支出（金额默认隐藏为 ¥****，点击卡片上的眼睛图标切换显示），点击「打开资产」跳转到资产页。

操作步骤：

1. 在今日日程或今日待办中，点击条目左侧/右侧的圆形勾选按钮即可标记完成，再次点击取消。
2. 点击问候卡片中的「每日计划」「资产」快捷入口，可快速跳转到对应页面；「资产」需先在功能广场添加到侧边栏后方可打开。
3. 在「心情打卡」卡片点击任一心情按钮即可完成当天打卡（再次点击当前档位表示取消记录），打卡后提示「打卡成功：今天的心情是『开心』」，取消时提示「已取消今天的心情打卡」。
4. 点击任意一张统计卡片（今日任务 / 习惯打卡 / 今日进度 / 今日状态），跳转到「每日计划」页面查看与操作对应内容。

空状态提示：今日日程为空时显示「今天还没有安排日程」；今日待办为空时显示「暂无待办事项」。

### 7.2 每日计划

#### 7.2.1 日期切换

功能说明：所有卡片随所选日期联动，可查看与规划任意一天。

操作步骤：

1. 页面右上角显示当前日期与星期。
2. 点击「前一天」按钮查看前一日，点击「后一天」按钮查看后一日。
3. 当所选日期不是今天时，会出现「回到今天」按钮，点击即可返回今日。

#### 7.2.2 日程

功能说明：日程是一天中带固定时间点的安排。

操作步骤（新增）：

1. 在「今日日程」卡片点击「添加日程」。
2. 在弹窗「标题」中填写内容，在「时间」中选择时间点，可选填「备注描述」。
3. 点击「保存」。保存成功后页面右上角提示「已保存」。

操作步骤（编辑/删除/完成）：

1. 将鼠标移到日程行上，行右侧会出现「编辑」「删除」按钮。
2. 点击「编辑」修改内容后「保存」；点击「删除」后，在确认弹窗中点击「确认删除」。
3. 点击行尾的圆形勾选按钮标记完成，已完成日程标题显示删除线，再次点击可取消。

字段含义：「标题」为日程名称；「时间」为日程开始时间点；「备注描述」为选填补充说明。

空状态提示：无日程时显示「还没有日程安排，点击「添加日程」开始规划」。

#### 7.2.3 待办

功能说明：待办是当日需要完成的事项，可关联一个时间段。

操作步骤：

1. 在「今日待办」卡片点击「添加待办」。
2. 填写「标题」，设置「开始时间」与「结束时间」。
3. 点击「保存」。
4. 点击待办行左侧的圆形勾选按钮标记完成（标题显示删除线），再次点击取消。
5. 鼠标悬停到行上，点击「编辑」或「删除」进行修改或删除；删除需在确认弹窗中点击「确认删除」。

字段含义：「标题」为待办内容；「开始时间」「结束时间」为待办时间段。

空状态提示：无待办时显示「暂无待办事项」；卡片标题右侧显示「N 项」总数。

#### 7.2.4 重要事项

功能说明：重要事项是当日重点，带高/中/低优先级色标，方便排定先后。

操作步骤：

1. 在「重要事项」卡片点击「添加」。
2. 填写「标题」，设置「开始时间」「结束时间」，在「优先级」中选择「高优先级」「中优先级」或「低优先级」。
3. 点击「保存」。
4. 点击行尾的圆形勾选按钮标记完成；鼠标悬停后可用「编辑」「删除」修改或删除。

字段含义：优先级色标含义为——高优先级（红色）、中优先级（黄色）、低优先级（绿色）。将鼠标悬停在圆点上可查看「高优先级」等提示。

空状态提示：无重要事项时显示「暂无重要事项」；卡片标题右侧显示「N 项」总数。

#### 7.2.5 习惯打卡

功能说明：习惯是需按天重复完成的目标，用进度环展示「已完成/目标」。

操作步骤（打卡）：

1. 在「习惯打卡」卡片点击某习惯的进度圆环，即可打卡一次（计数 +1）。
2. 打卡后习惯项右上角出现「−」按钮，点击可撤销一次打卡（计数 −1）。

操作步骤（管理习惯）：

1. 点击「管理习惯」打开管理弹窗，列表中显示每个习惯的图标、名称与「目标 N 次/天」。
2. 点击「新增习惯」，填写「习惯名称」，在「图标」中选择一个表情图标，设置「每日目标次数」（有效范围 1 至 20），点击「保存」。
3. 在管理列表点击某习惯的「编辑」可修改，点击「删除」删除（确认提示为「确定删除习惯「名称」吗？历史打卡记录将一并删除。」）；删除需点击「确认删除」。
4. 完成后点击「完成」关闭管理弹窗。

字段含义：「习惯名称」为目标名称；「图标」为进度环中心显示的表情；「每日目标次数」为每天需完成的目标次数。

空状态提示：无习惯时显示「还没有习惯，点击「管理习惯」添加」。

#### 7.2.6 专注计时

功能说明：针对当天「下一个任务」进行倒计时专注，完成后自动标记对应日程为已完成并记录专注时长。

操作步骤：

1. 在「下一个任务」卡片确认推荐的任务，点击「开始」。
2. 窗口右下角出现悬浮的专注卡片「专注中」，显示任务名称、倒计时（默认 30 分钟）、进度条。
3. 倒计时结束后，点击「完成」结束专注（记录实际专注分钟数，至少 1 分钟），此时会提示「已完成「任务名称」，专注 N 分钟」，并将该日程标记为完成。
4. 中途如需放弃，点击「放弃」或卡片右上角的「关闭」按钮，放弃不会记录专注时长。

注意事项：若当天日程已全部完成，在「下一个任务」卡片点击「开始」会提示「今日日程已全部完成，休息一下吧」。专注卡片位于窗口右下角，不会随页面切换而消失。

### 7.3 功能广场

功能说明：集中管理侧边栏显示哪些可配置功能，自由搭配出适合自己的工作台。首页 / 每日计划 / 日历 / 功能广场为固定项、设置在右上角，均不在广场中管理。

页面元素：

1. 顶部「已添加 n / 1 项功能」：显示当前已添加到侧边栏的可配置功能数与总数，右侧为「恢复默认」按钮；下方说明文案提示固定功能始终显示。
2. 分组功能网格：按「实用工具」分组展示可配置功能磁贴（当前为「资产」1 项）；磁贴包含图标、名称、描述与状态标签（「已添加到侧边栏 / 未添加」），右下角为「添加」「移除」与打开按钮；已添加的磁贴会描边高亮。

操作步骤：

1. 打开功能广场：点击侧边栏中的「功能广场」（固定显示，随时可进入）。
2. 添加功能：在未添加的功能磁贴上点击「添加」，提示「已添加「××」到侧边栏」，侧边栏立即出现该入口。
3. 移除功能：在已添加的功能磁贴上点击「移除」，提示「已移除「××」，数据不会丢失」。
4. 打开功能：点击磁贴右下角的箭头按钮，直接进入该功能页面。
5. 恢复默认：点击「恢复默认」，提示「已恢复默认侧边栏（仅保留固定功能）」，可配置功能全部从侧边栏移除。

注意事项：

1. 固定四项（首页 / 每日计划 / 日历 / 功能广场）始终显示、不可移除，不会出现在广场网格中；设置入口位于窗口右上角。
2. 移除仅是隐藏入口，相关数据（如账户与收支记录）都会保留，可随时重新添加。
3. 侧边栏配置会随「设置 → 导出备份」一起备份，并在恢复时一并还原。
4. 已移除的可配置功能无法通过地址直接访问，会自动跳转到侧边栏中的第一个功能（首页）。

### 7.4 日历与生日提醒

功能说明：日历以月视图集中展示公历、农历、节气、传统节日与法定节假日，并标注当天日程、生日、倒数日、纪念日与每日心情；它既是查看日期、节假日与天气的信息入口，也是管理生日、倒数日与纪念日、记录心情、接收生日提醒的页面。页头副标题为「节假日、农历、日程与生日提醒，右键日期快速添加」。

#### 7.4.1 打开日历

操作步骤：

1. 点击首页右上角的日期胶囊，即可跳转到「日历」页。
2. 点击「每日计划」右上角的日期胶囊，同样可跳转到「日历」页。
3. 也可直接点击侧边栏中固定显示的「日历」进入。

注意事项：「日历」固定显示在侧边栏（无需添加），通过上述日期胶囊也可随时打开。

#### 7.4.2 月视图读法

页面元素：

1. 月视图采用 6×7 网格（周一起始），每格显示公历日期；周末日期以红色显示。
2. 农历：单元格显示农历日，农历初一显示当月农历月名（选中日详情中同时显示干支纪年）。
3. 节气：如「寒露」「霜降」等节气名称显示在对应日期。
4. 节日：传统节日（含除夕）显示在对应日期。
5. 节假日角标：法定节假日显示「休」角标，调休上班日显示「班」角标。
6. 标记圆点：当天有日程显示绿点，有生日显示黄点，有倒数日或纪念日显示玫红色圆点（图例中有对应说明）。
7. 心情表情：日期格右下角显示当天心情表情（如 😄），无记录时不显示；图例中新增「当日心情」一项。

操作步骤：

1. 点击「上一月」「下一月」切换月份；点击「回到今天」返回当前月份。
2. 点击相邻月份的日期会自动切换到该月。
3. 将鼠标悬停在某个日期单元格上，可查看完整信息提示（tooltip）。

#### 7.4.3 右键快捷菜单

功能说明：在月视图中右键点击任意日期，弹出功能菜单，可快速添加生日、日程、倒数日或纪念日。

操作步骤：

1. 在月视图中右键点击目标日期，弹出功能菜单，包含「添加生日」「添加日程」「倒数日」「纪念日」四项；菜单会自动避开屏幕边缘。
2. 点击页面空白处即可关闭菜单。
3. 选择「添加生日」：打开新增生日弹窗，并按右键的日期预填「月份」与「日期」。
4. 选择「添加日程」：打开新增日程弹窗，默认「时间」为 09:00。
5. 选择「倒数日」或「纪念日」：打开对应的新增弹窗（详见 7.4.7）。

#### 7.4.4 当日详情

功能说明：在月视图中选中某一天后，页面显示该日的详情卡片。

页面元素：

1. 公历日期与星期，若为当天则显示「今天」标签。
2. 农历信息，例如「农历八月廿九」「丙午年」（干支纪年）。
3. 节气与节日（如有）。
4. 放假或调休信息，例如「国庆节 休假」「国庆节 补班」。
5. 当天日程列表（可勾选完成）。
6. 当天生日（如有）。
7. 倒数日 / 纪念日：当天命中的倒数日与纪念日条目（如有，详见 7.4.7）。
8. 心情：小尺寸心情选择器，可回看、补记或取消当日心情（详见 7.4.9）。

操作步骤：

1. 在月视图中点击某一天，查看其当日详情。
2. 在当天日程列表中点击圆形勾选按钮可标记完成，操作会同步更新该日程。

#### 7.4.5 生日管理

功能说明：生日管理卡片列出全部生日，并支持新增、编辑与删除。

页面元素：生日列表每项显示姓名、公历/农历标签、生日日期文案与下次发生日；命中提醒窗口或当天时显示「提醒中」或「今天生日」标记。

操作步骤（新增/编辑）：

1. 在「生日管理」卡片点击「新增生日」（或对已有生日点击「编辑」）。
2. 在弹窗中填写「姓名」，选择「历法」（公历 / 农历），设置「月份」「日期」，选择「提前提醒」（0/1/3/7/15/30 天），可选填「备注」。
3. 点击「保存」。

操作步骤（删除）：

1. 在生日列表点击「删除」，在二次确认弹窗中点击「确认删除」。

字段含义：公历生日按公历月份与日期记录；农历生日按对应农历年换算为当年公历日期，闰月按同号月份处理；农历三十在只有 29 天的月份会回退到当月最后一天。姓名为空时回退显示为「未命名」。

#### 7.4.6 生日提醒

功能说明：生日提醒在应用内以首页卡片展示，并在到达提醒窗口时弹出 Windows 系统通知。

页面元素：首页「生日提醒」卡片在未来 60 天内有生日时显示，最多列出 4 条（姓名、公历/农历、还有 N 天 / 今天），并提供「打开日历」按钮。

操作步骤：

1. 应用运行期间，在启动时以及之后每 30 分钟检查一次生日。
2. 当到达某条生日设置的「提前提醒天数」窗口时，弹出标题为「生日提醒」的 Windows 系统通知。
3. 在首页「生日提醒」卡片点击「打开日历」，进入日历页查看与管理。

注意事项：同一天的同一个生日只会提醒一次。

#### 7.4.7 倒数日与纪念日

功能说明：倒数日用于倒数一个一次性日期，纪念日为每年重复的日期；两者在月视图上以玫红色圆点标记，并集中在侧栏的「倒数日与纪念日」管理卡中维护。

字段含义：

1. 倒数日：一次性日期，必须选择年份（不选会有错误提示）；到达该日期后显示「已过 N 天」。
2. 纪念日：每年重复，「起始年份」选填——不记录年份则不计算周年；填写后显示「第 N 周年」；2 月 29 日的纪念日在平年按 2 月 28 日提醒。

页面元素：侧栏「倒数日与纪念日」管理卡按剩余天数排序列出全部条目，卡片上有「倒数日」「纪念日」两个添加按钮，每条支持「编辑」「删除」；选中日详情中新增「倒数日 / 纪念日」小节，展示当天命中的条目。

操作步骤：

1. 在管理卡点击「倒数日」或「纪念日」（也可在月视图右键日期后选择对应项），填写名称与日期等信息，点击「保存」。
2. 在管理卡中点击条目的「编辑」进行修改；点击「删除」，在二次确认弹窗中点击「确认删除」。

#### 7.4.8 未来一周天气

功能说明：日历页月视图卡片顶部展示「未来一周天气」横条，显示今天起未来 7 天（今天 + 未来 6 天）的天气情况。数据来自 Open-Meteo 免费预报服务，无需配置密钥。

页面元素：

1. 横条右上角显示定位城市（带定位图标，如「上海」；无法定位时回退到内置默认城市并显示「北京（默认）」）、更新时间与「刷新」按钮。
2. 7 天天气：每天显示「今天 / 周几 + 天气图标 + 天气描述 + 最低~最高温度」；今天所在的天气项带高亮描边。
3. 天气描述与图标由 WMO 天气码映射为中文（如晴、晴间多云、多云、阴、雾、毛毛雨、小雨、中雨、大雨、冻雨、小雪、中雪、大雪、阵雨、暴雨、阵雪、雷阵雨、雷阵雨伴冰雹等），未收录的天气码显示「未知」。

操作步骤：

1. 打开日历页，天气横条自动展示当前定位城市未来一周的天气。
2. 点击右上角「刷新」，可强制重新获取最新天气；不点击时结果缓存 30 分钟，频繁打开不会重复请求。

注意事项：

1. 断网或定位失败时，界面展示最近一次缓存数据并提示「网络不可用，当前展示最近一次缓存数据」；若此前没有任何缓存，则提示「获取天气失败，请检查网络连接后重试」。
2. 窗口较窄（宽度不超过 700px）时，天气横条隐藏文字描述，仅保留天气图标与温度，避免布局溢出。

#### 7.4.9 每日心情

功能说明：每日心情支持在日历中回看、补记或取消任意一天的心情记录，与首页「心情打卡」卡片共享同一份数据，实时同步。

页面元素：

1. 月视图：每个日期格右下角显示当天的心情表情（如 😄），无记录时不显示。
2. 图例：新增「当日心情」一项；将鼠标悬停在日期格上，提示信息中包含「心情：开心」。
3. 选中日详情：新增「心情」小节，提供小尺寸心情选择器（5 档）。

操作步骤：

1. 在月视图点击某一天查看当日详情，在「心情」小节点击任一档位即可记录该日心情（可为任意日期补记）。
2. 再次点击当天已选中的档位表示取消记录；记录后提示「已记录 10月9日 的心情：开心」。

注意事项：心情共 5 档——糟糕 / 低落 / 一般 / 不错 / 开心；在首页或日历任一入口记录，另一处会同步更新。

### 7.5 资产

功能说明：资产用于集中管理各平台账户余额、记录日常收支、查看统计图表，并跟踪攒钱目标与想买的商品。删除操作均需二次确认，表单非法输入（如金额必须大于 0、名称必填）会有错误提示。

进入方式：在「功能广场」中将「资产」添加到侧边栏（见 7.3），再点击侧边栏中的「资产」进入。

页面结构：页头为「记收入」「记支出」按钮；其下为概览四卡片；主体分为「账户与收支」「统计图表」「攒钱与想买」三个页签。

#### 7.5.1 概览卡片与金额隐藏

页面元素：

1. 概览四卡片：总资产（含账户数量）、本月收入、本月支出、攒钱进度（已达成 / 目标数）。
2. 金额默认隐藏，显示为「¥****」；点击卡片上的眼睛图标即可显示实际金额（千分位、两位小数格式），再次点击恢复隐藏。

#### 7.5.2 账户管理

功能说明：账户是收支记录的归属，支持 12 个平台：支付宝、微信支付、京东金融、工商银行、建设银行、农业银行、中国银行、招商银行、交通银行、邮储银行、现金、其他平台。各平台图标为品牌色徽章加白色字形（如蓝色「支」、绿色「微」）。

操作步骤（新增）：

1. 在「账户与收支」页签的账户列表点击「添加账户」。
2. 选择「平台」，填写「名称」「初始余额」，可选填「备注」。
3. 点击「保存」；名称为空时会提示必填。

操作步骤（编辑/删除）：

1. 点击账户上的「编辑」，修改后「保存」。
2. 点击「删除」，在二次确认弹窗中确认；删除账户会级联删除该账户的全部收支记录。

#### 7.5.3 收支记账

功能说明：按账户记录收入与支出，支持筛选与修改；金额变动会自动同步账户余额。

操作步骤（记账）：

1. 点击页头的「记收入」或「记支出」。
2. 选择「账户」与「分类」，填写「金额」（必须大于 0）、「日期」，可选填「备注」。
3. 点击「保存」。

分类说明：收入分类共 7 类——工资、奖金、兼职、理财收益、红包转账、报销退款、其他收入；支出分类共 9 类——餐饮、购物、交通、住房、娱乐、医疗、教育、人情、其他支出。

操作步骤（筛选/编辑/删除）：

1. 按「月份」筛选收支记录，或在「收入 / 支出 / 全部」之间切换类型筛选。
2. 点击记录的「编辑」：保存时会先冲正旧金额、再按新值入账，操作前有确认提示。
3. 点击记录的「删除」：确认后自动冲正该笔金额对应的账户余额。

#### 7.5.4 统计图表

页面元素（「统计图表」页签）：

1. 资产分布饼图：按账户展示资产占比，账户超过 7 个时合并为「其他」。
2. 近 30 天总资产趋势线：展示总资产随时间的变化。
3. 当月收入分类与支出分类条形图：随收支筛选的月份联动变化。

#### 7.5.5 攒钱与想买

功能说明：在「攒钱与想买」页签内可切换「攒钱计划 / 想买」：攒钱计划用于设定储蓄目标，想买用于记录目标商品（如 MacBook Pro ¥15999），两者以目标卡片形式展示。

操作步骤（新建目标）：

1. 切换到「攒钱计划」或「想买」，点击「新建目标」。
2. 填写「名称」「目标金额」，选择「存钱周期」（每日 / 每周 / 每月 / 每年 / 不自动）；选择自动周期时需填写「每次存入金额」（如每月存 ¥2500）。
3. 点击「保存」。

页面元素：每个目标卡片显示进度条、百分比、已存 / 目标金额与自动计划描述（如「每月存 ¥2,500.00 · 约 12 个月达成」）。

操作步骤（存入/达成/编辑/删除）：

1. 点击卡片的「存入」记录一次存入，弹窗默认填入计划金额，可修改后确认。
2. 进度达到 100% 时自动标记「已达成」，并停止继续存入。
3. 点击「编辑」修改目标；点击「删除」，在二次确认弹窗中确认；删除目标会级联删除其存入明细。

#### 7.5.6 首页联动

功能说明：切换界面主题配色，个性化昵称，管理数据备份与恢复，查看关于信息。

打开方式：点击窗口右上角的齿轮按钮（位于最小化按钮左侧），当前处于设置页时按钮高亮。

页面元素：分为「外观主题」「个人资料」「数据安全」「关于」四个区块。

操作步骤（外观主题）：

## 8. 数据管理

### 8.1 数据存储位置

1. 默认情况下，数据库文件位于本机数据目录：`%APPDATA%\Workbench\data\workbench.db`（WAL 模式）。
2. 可在「设置」→「数据安全」→「更改数据存储位置」把数据改存到其他文件夹：应用会在所选文件夹下创建 `Workbench` 子目录并复制数据库，随后立即切换到新位置；原位置文件保留作为兜底备份（确认新位置正常后可自行删除）。当前使用的目录配置记录在 `%APPDATA%\Workbench\storage.json` 中，下次启动自动生效。
3. 在「设置」→「数据安全」中点击「打开目录」可直接定位当前使用的数据目录；「数据存储位置」一行也会始终显示当前数据库文件的完整路径。
4. 便携模式（见 10.2）下数据位置由启动参数固定，不支持在应用内更改。
5. 应用不联网上传数据，所有记录均保存在本机。

### 8.2 备份（导出）

操作步骤：

1. 进入「设置」→「数据安全」。
2. 点击「导出备份」。
3. 在系统保存对话框中选择保存位置与文件名，确认保存。
4. 保存成功提示「备份已导出」。

影响范围：导出为 JSON 文件，包含全部业务数据（日程、待办、习惯及打卡、重要事项、生日、倒数日与纪念日、每日心情、账户与收支记录、攒钱目标、侧边栏配置与设置等）。导出操作不会修改现有数据。

### 8.3 恢复（导入）

操作步骤：

1. 进入「设置」→「数据安全」。
2. 点击「导入恢复」。
3. 在确认弹窗中阅读提示后点击「继续导入」。
4. 选择此前导出的 JSON 备份文件，确认导入。
5. 导入成功后提示「数据已恢复，正在刷新…」，界面自动刷新。

影响范围：导入会用备份文件覆盖本机现有全部数据，且无法撤销。若备份文件格式不正确，会提示「备份文件格式不正确，无法恢复」。恢复前建议先导出一份当前数据作为保险。

### 8.4 导出为 JSON（迁移/留档）

导出数据即第 8.2 节的 JSON 备份文件，可用于迁移到新电脑或长期留档。

### 8.5 清空数据

本版本「设置」中未提供一键「清空数据」的按钮。如需彻底重置数据，建议按以下步骤稳妥处理：

1. 先在「设置」中点击「导出备份」，保存一份备份以防误操作。
2. 完全退出应用（点击窗口右上角「关闭」）。
3. 在「设置」→「数据安全」点击「打开目录」（或手动打开 `%APPDATA%\Workbench\data`），删除其中的 `workbench.db` 文件（如存在同名的 `-wal`、`-shm` 文件，一并删除）。
4. 重新启动应用，将自动创建全新的空数据库。

影响范围：删除数据库文件后原有全部记录不可恢复，请务必先完成备份。卸载应用本身不会自动删除该文件，需要手动清理。

### 8.6 迁移到新电脑

操作步骤：

1. 在旧电脑上进入「设置」→「数据安全」，点击「导出备份」，得到 JSON 备份文件。
2. 将 JSON 备份文件复制到新电脑。
3. 在新电脑安装并启动 Workbench。
4. 进入「设置」→「数据安全」，点击「导入恢复」，按提示选择该 JSON 文件并「继续导入」。
5. 导入完成后界面自动刷新，数据即迁移完成。

## 9. 常见问题 FAQ

1. 我的数据存在哪里？
   答：默认保存在本机数据目录的 `workbench.db` 文件中，路径为 `%APPDATA%\Workbench\data\workbench.db`（WAL 模式）。可在「设置」→「数据安全」点击「打开目录」查看；也可以在「更改数据存储位置」中把数据改存到其他文件夹，当前完整路径会显示在「数据存储位置」一行。

2. Workbench 会联网吗？会上传我的数据吗？
   答：不会上传数据。应用数据只保存在本机；除日历页「未来一周天气」需联网获取 Open-Meteo 预报数据外，其余功能均离线可用。

3. 如何把数据迁移到另一台电脑？
   答：先在原电脑「设置」中「导出备份」，把 JSON 文件复制到新电脑，在新电脑用「导入恢复」载入即可（详见第 8.6 节）。

4. 误删了日程/待办/收支等记录，能恢复吗？
   答：应用内的删除是即时的，没有回收站。若有较新的 JSON 备份，可通过「导入恢复」找回备份时的状态（会覆盖当前全部数据）；若没有备份则无法恢复。建议定期备份。

5. 安装时被 SmartScreen 或杀毒软件拦截/报毒怎么办？
   答：安装包未做代码签名，Windows 可能提示「Windows 已保护你的电脑」。此时点击「更多信息」→「仍要运行」即可继续；如被第三方杀毒软件拦截，可在确认安装包来源可靠后将其加入信任/白名单。若仍有顾虑，请核对安装包名称与大小是否与官方交付一致。

6. 数据清空/删库后能撤销吗？
   答：不能。删除 `workbench.db` 属于不可逆操作，且应用内「导入恢复」只能恢复备份文件中的内容。执行前请务必先「导出备份」。

7. 卸载应用会删除我的数据吗？
    答：不会自动删除。数据文件位于独立的数据目录，卸载程序不会移除它。如需彻底清理，请在卸载前先备份，卸载后手动删除数据目录中的文件。

## 10. 开发者与高级用法

本章面向希望自行运行或打包源码的开发者。

### 10.1 npm 命令一览

| 命令 | 说明 |
| --- | --- |
| `npm install` | 安装依赖 |
| `npm run dev` | 启动开发模式（带热更新） |
| `npm run start` | 预览已构建产物 |
| `npm run typecheck` | 类型检查（主进程 + 渲染进程） |
| `npm test` | 运行单元测试 |
| `npm run test:watch` | 以监听模式运行测试 |
| `npm run build` | 构建生产代码 |
| `npm run dist` | 构建并生成 Windows NSIS 安装包 |

打包产物位于 `dist/`，安装包名为 `Workbench-1.0.0-Setup.exe`。运行环境要求 Node.js 18 及以上。

### 10.2 便携模式（WORKBENCH_DATA_DIR）

1. 应用支持通过环境变量 `WORKBENCH_DATA_DIR` 指定自定义数据目录，用于开发调试或便携使用。
2. 当设置了该变量时，应用的用户数据目录会被指向该路径，数据库文件位于其下的 `data/` 子目录中，从而实现「数据与程序放在一起」的便携模式。
3. 便携模式优先级最高：此时「设置」中的「更改位置」按钮不可用（由启动参数固定数据位置），已保存的「数据存储位置」配置也不会生效。

### 10.3 技术栈（供参考）

Electron 44（无边框窗口）+ Vue 3 + TypeScript + Pinia + Vue Router + SQLite（优先 better-sqlite3，自动回退 Node 内置 node:sqlite），打包使用 electron-builder。

## 11. 快捷键与技巧

### 11.1 键盘操作说明

本版本以鼠标操作为主，未内置全局键盘快捷键。以下键盘交互与系统窗口行为仍然可用：

1. 在弹窗表单中，光标位于「标题」等输入框时按回车可直接提交保存（例如日程、待办、重要事项、收支记录、习惯、昵称等输入框）。
2. 双击窗口顶部拖拽区域可切换最大化/还原。

### 11.2 鼠标技巧

1. 列表行（日程、待办、重要事项、生日、收支记录、攒钱目标）的「编辑」「删除」按钮在鼠标悬停时才会显示，将鼠标移到该行即可看到。
2. 在习惯打卡区，点击进度环打卡，悬停习惯项可看到右上角的「−」撤销按钮。
3. 点击圆形勾选按钮可快速切换完成状态，无需进入编辑弹窗。
4. 专注计时卡片固定在窗口右下角，切换页面时不会消失。

### 11.3 使用建议

1. 每天先到「每日计划」安排日程与待办，再用首页概览跟踪进度。
2. 习惯目标次数不宜设置过高，保持可持续的打卡节奏更利于形成连续天数。
3. 用「资产」记录日常收支并跟踪攒钱进度，定期导出备份以防数据丢失。
