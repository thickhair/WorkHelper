## 1. 项目概述

### 1.1 项目背景
面向个人用户的日常效率管理工具。用户需要一个集「任务管理、日程安排、习惯打卡、心情记录、资产管理」于一体的桌面工作台，用于规划每一天的工作与生活，并管理个人资金与攒钱目标。

### 1.2 设计目标
- 参照 `图片_20261008191001_27_69.jpg` 设计稿高度还原视觉效果（绿色主题、白色圆角卡片、进度环、双栏内容布局）。
- 全部功能离线可用，数据仅存储在本地，保障用户隐私。
- 冷启动时间 < 3 秒，常驻内存占用合理（< 300MB）。
- 支持 Windows 10 及以上操作系统。

### 1.3 术语定义
| 术语 | 说明 |
| --- | --- |
| 日程（Schedule） | 一天中带固定时间的安排，如「07:00 起床+早餐」 |
| 待办（Todo） | 当日需要完成的事项，可关联时间段 |
| 习惯（Habit） | 需要按天重复打卡的目标，如「多喝水 2 次/天」 |
| 重要事项（Priority） | 当日重点事项，带高/中/低优先级色标 |
| 生日（Birthday） | 自建的生日记录，支持公历或农历、提前提醒天数与备注 |
| 倒数日（Countdown） | 指向某个确定日期（含年）的一次性倒计时，到达后显示「已过 N 天」 |
| 纪念日（Anniversary） | 每年重复的日子（月/日），起始年份选填，填写后展示「第 N 周年」 |
| 资产账户（Asset Account） | 某个平台（支付宝/微信/银行等）下的资金账户，记录当前余额 |
| 攒钱计划 / 想买（Saving Goal） | 自定义目标金额与存钱周期（想买 = 目标商品），按存入明细实时展示进度 |

## 2. 功能需求

### 2.1 全局框架
| 编号 | 功能 | 说明 |
| --- | --- | --- |
| G-01 | 无边框窗口 | 自定义标题栏（最小化/最大化/关闭），支持拖拽移动、双击最大化；右上角常驻「设置」入口（齿轮按钮，当前处于设置页时高亮） |
| G-02 | 左侧导航栏 | 绿色主题侧边栏：首页 / 每日计划 / 日历 / 功能广场四项固定显示（不可移除），其余功能按配置动态展示（见 F-01~F-03），当前项高亮，支持滚动 |
| G-03 | 路由切换 | 页面切换无刷新，切换时保持数据实时性 |
| G-04 | 数据持久化 | 所有操作实时写入本地 SQLite 数据库 |

### 2.2 首页（仪表盘）
| 编号 | 功能 | 说明 |
| --- | --- | --- |
| H-01 | 问候卡片 | 根据当前时间动态问候（早上好/下午好/晚上好），显示当天日期、星期与一句鼓励语 |
| H-02 | 今日概览 | 今日任务完成 n/m、习惯打卡 n/m、今日进度百分比、今日状态（由完成率推导）；四张统计卡片整体可点击，点击跳转到「每日计划」 |
| H-03 | 今日日程简表 | 展示前 5 条日程及完成状态，可勾选 |
| H-04 | 今日待办简表 | 展示前 5 条待办，可勾选 |
| H-05 | 近 7 天趋势 | 迷你柱状图展示最近 7 天任务完成数量 |
| H-06 | 快捷入口 | 一键跳转「每日计划 / 资产」（展示侧边栏中的功能，固定功能始终包含） |
| H-07 | 生日提醒卡片 | 未来 60 天内有生日时展示临近生日列表（姓名、公历/农历、剩余天数），可跳转日历 |
| H-08 | 日期入口 | 右上角日期胶囊可点击，跳转到日历页 |
| H-09 | 心情打卡 | 首页「心情打卡」卡片，5 档心情一键记录；未打卡时提示「今天还没打卡」，打卡后显示「已打卡 · 连续打卡 N 天」（从今天往前回溯统计连续记录天数）；再次点击当前档位表示取消记录；记录结果可在日历中回看与补记 |
| H-10 | 资产概览 | 资产功能加入侧边栏后展示：总资产、本月收入、本月支出；金额默认隐藏（¥****），点击眼睛图标切换显示；含「打开资产」跳转入口 |

### 2.3 每日计划
| 编号 | 功能 | 说明 |
| --- | --- | --- |
| D-01 | 日期切换 | 支持前一天/后一天/回到今天，所有卡片随日期联动 |
| D-02 | 统计卡片 | 今日任务 x/y、习惯打卡 x/y、今日进度 %、今日状态四卡片 |
| D-03 | 今日日程 | 列表展示（时间、标题、描述、完成勾选）；支持新增/编辑/删除 |
| D-04 | 今日待办 | 列表展示（完成勾选、标题、时间段）；支持新增/编辑/删除；显示总项数 |
| D-05 | 习惯打卡 | 进度环展示每个习惯「已完成/目标」；点击打卡（+1，可撤销）；支持新增/编辑/删除习惯 |
| D-06 | 重要事项 | 列表展示（优先级色标、时间段、完成勾选）；支持新增/编辑/删除；显示总项数 |
| D-07 | 下一个任务 | 自动推荐当天最近未完成的日程；点击「开始」进入专注计时，完成后标记日程完成 |

### 2.4 资产
| 编号 | 功能 | 说明 |
| --- | --- | --- |
| A-01 | 多平台账户 | 内置 12 个平台目录（支付宝 / 微信支付 / 京东金融 / 工商 / 建设 / 农业 / 中国 / 招商 / 交通 / 邮储银行 / 现金 / 其他），每个平台使用自绘品牌色 SVG 徽章（离线可用）；账户支持手动添加、编辑与删除（删除级联其收支记录，二次确认） |
| A-02 | 收支记录 | 收入 / 支出分类记账（收入 7 类、支出 9 类），含金额、日期、账户、备注；支持月份筛选与收支类型筛选；新增、编辑（先冲正旧值再入新值）、删除（自动冲正）均在事务中联动账户余额 |
| A-03 | 概览卡片 | 总资产、本月收入、本月支出、攒钱进度（已达成/目标数）四卡片；金额默认隐藏（¥****），点击眼睛图标切换显示 |
| A-04 | 统计图表 | 资产分布饼图（按账户，前 7 名 + 其他合并）、近 30 天总资产趋势线（以当前余额按窗口内收支逐日回推）、当月收入 / 支出分类条形图；纯 SVG 绘制，离线渲染 |
| A-05 | 攒钱计划 | 自定义目标名称、目标金额与存钱周期（每日 / 每周 / 每月 / 每年 / 不自动，自动周期需设置每次存入金额）；按存入明细实时显示进度条与百分比，达标后自动标记「已达成」 |
| A-06 | 「想买」 | 输入目标商品金额创建想买目标，其余与攒钱计划一致：手动存入或按周期计划存入，实时显示存钱进度，达标提示 |
| A-07 | 金额隐私 | 资产页与首页概览的金额默认以 ¥**** 隐藏，点击眼睛图标后显示实际金额（千分位两位小数） |

### 2.5 设置与数据安全
| 编号 | 功能 | 说明 |
| --- | --- | --- |
| T-01 | 数据备份 | 导出全部数据为 JSON 文件（用户自选保存路径） |
| T-02 | 数据恢复 | 从 JSON 备份文件导入并覆盖本地数据（二次确认） |
| T-03 | 打开数据目录 | 在资源管理器中定位数据库文件 |
| T-04 | 关于信息 | 显示版本、技术栈与数据存储位置 |
| T-05 | 外观主题 | 内置 6 套主题（森林绿、海洋蓝、樱花粉、暖阳橙、紫罗兰、暗夜黑），设置页点击卡片即时全局换肤并自动持久化，下次启动自动恢复 |
| T-06 | 更改数据存储位置 | 设置页可更改数据库存放文件夹：二次确认后选择目标文件夹，自动创建 `Workbench` 子目录并把数据库复制过去、立即切换使用（原位置文件保留）；目标文件夹已有 Workbench 数据时拒绝切换；便携模式下不可更改 |

### 2.6 功能广场
| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F-01 | 功能广场 | 按分组以网格形式展示全部可配置功能磁贴（当前为「资产」，属「实用工具」分组；首页 / 每日计划 / 日历 / 功能广场为固定项、设置位于右上角，均不在广场中管理）；每个功能磁贴的图标使用独立色调与徽章样式（实心渐变 / 柔和底色 / 描边环），图标契合功能含义；磁贴含名称、描述与状态，支持添加、移除与一键恢复默认 |
| F-02 | 侧边栏自定义 | 首页 / 每日计划 / 日历 / 功能广场固定显示在侧边栏顶部（无移除按钮）；可配置功能可在功能广场添加或移除，已添加项悬停显示移除按钮；窗口宽度不超过 860px 时侧边栏自动收起为图标模式 |
| F-03 | 配置持久化 | 侧边栏配置仅记录可配置功能（固定功能不写入配置，历史配置中的固定项 / 设置项 / 已删除功能项被自动过滤），随数据备份/恢复一并迁移；已移除的可配置功能不可直接访问（自动跳转到侧边栏第一个功能，即首页）；固定功能与设置始终可访问 |

### 2.7 日历与生日提醒
| 编号 | 功能 | 说明 |
| --- | --- | --- |
| C-01 | 日期入口 | 首页与「每日计划」右上角日期胶囊可点击，跳转日历页；日历作为日期入口始终可访问（无需加入侧边栏） |
| C-02 | 月视图 | 6×7 网格展示公历日期、农历日/月名、节气、传统节日（含除夕）、法定节假日「休/班」标记与日程/生日圆点；支持上一月/下一月/回到今天，点击相邻月日期自动切换月份 |
| C-03 | 当日详情 | 展示选中日期的农历（含干支纪年）、节气、节日、放假/调休名称，以及当天日程（可勾选完成）与生日 |
| C-04 | 生日管理 | 自建生日记录（姓名、公历/农历、月日、提前提醒天数 0-60 天、备注），支持编辑与删除；农历生日按对应农历年自动换算为公历日期（闰月按同号月份计算，农历三十在 29 天的月份按当月最后一天） |
| C-05 | 生日提醒 | 到达提前提醒天数时，应用运行期间通过 Windows 系统通知提醒（同一天同一人仅提醒一次）；首页在 60 天内有生日时展示「生日提醒」卡片 |
| C-06 | 节假日与农历数据 | 内置国务院办公厅 2024-2026 年放假安排（含调休），未收录年份回退到历法库数据；农历、节气、干支与传统节日基于 lunar-javascript 精确历法 |
| C-07 | 未来一周天气 | 日历页展示今天起未来 7 天天气（天气图标、中文描述、最低~最高温度），通过 IP 自动定位城市；支持手动刷新，结果缓存 30 分钟；断网时展示最近一次缓存并提示 |
| C-08 | 每日心情 | 月视图每个日期显示当日心情表情，选中可回看、补记或取消；与首页「心情打卡」记录实时同步 |
| C-09 | 日期右键菜单 | 右键点击月视图任意日期弹出功能菜单：添加生日（按所选日期预填月日）、添加日程（默认 09:00）、倒数日、纪念日；菜单自动避开屏幕边缘，点击遮罩或再次右键关闭；各菜单项直接打开对应添加弹窗 |
| C-10 | 倒数日与纪念日 | 倒数日为一次性日期（含年份，到达后显示「已过 N 天」）；纪念日每年重复（起始年份选填，填写后显示「第 N 周年」，2 月 29 日平年回退 2 月 28 日）；月视图以玫红圆点标记，选中日详情与侧栏「倒数日与纪念日」管理卡（按剩余天数排序）支持新增、编辑、删除 |

## 3. 非功能需求
| 类别 | 要求 |
| --- | --- |
| 性能 | 冷启动 < 3s；页面切换 < 200ms；列表操作无明显卡顿 |
| 稳定性 | 数据库启用 WAL 模式与事务写入；异常时界面提示且不崩溃 |
| 安全 | 渲染进程开启 contextIsolation、禁用 nodeIntegration；仅通过白名单 IPC 通信 |
| 可用性 | 关键操作有确认/反馈；空状态有引导文案 |
| 可维护性 | TypeScript 全量类型约束；分层架构（渲染层/预加载层/主进程服务层/数据层）；核心逻辑单元测试覆盖 |
| 兼容性 | Windows 10 1809 及以上（x64） |

## 5. 数据需求（本地 SQLite）
数据库文件：`%APPDATA%/Workbench/workbench.db`（WAL 模式）。核心表：`settings`、`schedules`、`todos`、`habits`、`habit_logs`、`priorities`、`focus_logs`、`birthdays`、`moods`、`anniversaries`、`asset_accounts`、`asset_records`、`saving_goals`、`saving_deposits`。详见《数据库设计说明书》。

## 6. 验收标准
1. 界面与设计稿布局、配色、圆角卡片风格一致，窗口缩放时布局响应正常。
2. 2.2~2.7 全部功能可用，数据关闭应用后不丢失。
3. `npm run test` 单元测试全部通过；`npm run dist` 产出 NSIS 安装包，安装后可正常启动、卸载。
4. 无未捕获异常导致的白屏或崩溃。
