# 个人工作台（WorkHelper）功能规格说明书

| 项目名称 | 个人工作台 WorkHelper | 版本 | V1.0 |
| --- | --- | --- | --- |
| 文档类型 | 需求分析与功能规格说明书 | 编写日期 | 2026-10-08 |
| 适用平台 | Windows 10 / 11（x64） | 技术栈 | Electron + Vue 3 + TypeScript + SQLite |

## 1. 项目概述

### 1.1 项目背景
面向个人用户的日常效率管理工具。用户需要一个集「任务管理、日程安排、习惯打卡、笔记记录、数据统计」于一体的桌面工作台，用于规划每一天的学习与工作内容，并沉淀复盘数据。

### 1.2 设计目标
- 参照 `图片_20261008191001_27_69.jpg` 设计稿高度还原视觉效果（绿色主题、白色圆角卡片、进度环、双栏内容布局）。
- 全部功能离线可用，数据仅存储在本地，保障用户隐私。
- 冷启动时间 < 3 秒，常驻内存占用合理（< 300MB）。
- 支持 Windows 10 及以上操作系统。

### 1.3 术语定义
| 术语 | 说明 |
| --- | --- |
| 日程（Schedule） | 一天中带固定时间的安排，如「07:00 起床+早餐」 |
| 待办（Todo） | 当日需要完成的事项，可关联时间段 |
| 习惯（Habit） | 需要按天重复打卡的目标，如「多喝水 2 次/天」 |
| 重要事项（Priority） | 当日重点事项，带高/中/低优先级色标 |
| 分类模块（Module） | 侧边栏中的学习/生活主题空间，用于记录投入与笔记 |
| 复盘（Review） | 每日工作复盘笔记 |

## 2. 功能需求

### 2.1 全局框架
| 编号 | 功能 | 说明 |
| --- | --- | --- |
| G-01 | 无边框窗口 | 自定义标题栏（最小化/最大化/关闭），支持拖拽移动、双击最大化 |
| G-02 | 左侧导航栏 | 绿色主题侧边栏，默认含 15 个功能入口与「功能广场」，可自定义添加/移除（见 F-01~F-04），当前项高亮，支持滚动 |
| G-03 | 路由切换 | 页面切换无刷新，切换时保持数据实时性 |
| G-04 | 数据持久化 | 所有操作实时写入本地 SQLite 数据库 |

### 2.2 首页（仪表盘）
| 编号 | 功能 | 说明 |
| --- | --- | --- |
| H-01 | 问候卡片 | 根据当前时间动态问候（早上好/下午好/晚上好），显示当天日期、星期与一句鼓励语 |
| H-02 | 今日概览 | 今日任务完成 n/m、习惯打卡 n/m、今日进度百分比、今日状态（由完成率推导） |
| H-03 | 今日日程简表 | 展示前 5 条日程及完成状态，可勾选 |
| H-04 | 今日待办简表 | 展示前 5 条待办，可勾选 |
| H-05 | 近 7 天趋势 | 迷你柱状图展示最近 7 天任务完成数量 |
| H-06 | 快捷入口 | 一键跳转「每日计划 / 数据统计 / 工作复盘」（仅展示已添加到侧边栏的功能） |

### 2.3 每日计划
| 编号 | 功能 | 说明 |
| --- | --- | --- |
| D-01 | 日期切换 | 支持前一天/后一天/回到今天，所有卡片随日期联动 |
| D-02 | 统计卡片 | 今日任务 x/y、习惯打卡 x/y、今日进度 %、今日状态四卡片 |
| D-03 | 今日日程 | 列表展示（时间、标题、描述、完成勾选）；支持新增/编辑/删除 |
| D-04 | 今日待办 | 列表展示（完成勾选、标题、时间段）；支持新增/编辑/删除；显示总项数 |
| D-05 | 习惯打卡 | 进度环展示每个习惯「已完成/目标」；点击打卡（+1，可撤销）；支持新增/编辑/删除习惯 |
| D-06 | 重要事项 | 列表展示（优先级色标、时间段、完成勾选）；支持新增/编辑/删除；显示总项数 |
| D-07 | 下一个任务 | 自动推荐当天最近未完成的日程；点击「开始」进入专注计时，完成后标记日程完成 |

### 2.4 分类模块（通用工作区，9 个：减肥运动、英语学习、剪辑学习、播客精选、表达能力、读书推荐、妆容穿搭、爆款二创、AI 学习）

| --- | --- | --- |
| M-01 | 模块概览 | 累计记录次数、累计投入时长、最近记录日期、本模块目标 |

| M-04 | 模块笔记 | 新增/编辑/删除笔记（标题、正文、更新时间） |

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| R-01 | 复盘列表 | 按日期倒序展示历史复盘 |
| R-02 | 撰写/编辑 | 每篇包含：今日完成、问题与反思、明日计划、今日心情（5 档）|
| R-03 | 删除 | 支持删除某日复盘 |

### 2.6 新闻资讯
| 编号 | 功能 | 说明 |
| --- | --- | --- |
| N-01 | 资讯列表 | 展示标题、来源、摘要、标签、收藏状态 |

### 2.7 数据统计
| 编号 | 功能 | 说明 |
| --- | --- | --- |
| S-01 | 关键指标 | 累计完成任务数、累计打卡次数、当前连续打卡天数、累计投入时长 |
| S-02 | 近 7 天任务完成趋势 | 柱状图（已完成/新增任务数） |

### 2.8 设置与数据安全
| 编号 | 功能 | 说明 |
| --- | --- | --- |
| T-01 | 数据备份 | 导出全部数据为 JSON 文件（用户自选保存路径） |
| T-02 | 数据恢复 | 从 JSON 备份文件导入并覆盖本地数据（二次确认） |
| T-03 | 打开数据目录 | 在资源管理器中定位数据库文件 |
| T-04 | 关于信息 | 显示版本、技术栈与数据存储位置 |
| T-05 | 外观主题 | 内置 6 套主题（森林绿、海洋蓝、樱花粉、暖阳橙、紫罗兰、暗夜黑），设置页点击卡片即时全局换肤并自动持久化，下次启动自动恢复 |

### 2.9 功能广场与专注空间
| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F-01 | 功能广场 | 按「常用功能 / 学习模块 / 实用工具 / 系统功能」分组展示全部功能卡片（图标、名称、描述、状态），支持添加、移除与一键恢复默认 |
| F-02 | 侧边栏自定义 | 侧边栏按配置动态生成；普通功能悬停显示移除按钮，可一键移除；首页、功能广场、设置为固定项不可移除 |
| F-03 | 配置持久化 | 侧边栏配置保存于本地 settings 表，随数据备份/恢复一并迁移；已移除的功能不可直接访问（自动回到首页） |
| F-04 | 专注空间 | 番茄式专注计时：可选 15/25/45/60 分钟预设，支持暂停/继续/放弃，完成后记录时长，并展示今日专注总时长与最近记录 |

## 3. 非功能需求
| 类别 | 要求 |
| --- | --- |
| 性能 | 冷启动 < 3s；页面切换 < 200ms；列表操作无明显卡顿 |
| 稳定性 | 数据库启用 WAL 模式与事务写入；异常时界面提示且不崩溃 |
| 安全 | 渲染进程开启 contextIsolation、禁用 nodeIntegration；仅通过白名单 IPC 通信 |
| 可用性 | 关键操作有确认/反馈；空状态有引导文案 |
| 可维护性 | TypeScript 全量类型约束；分层架构（渲染层/预加载层/主进程服务层/数据层）；核心逻辑单元测试覆盖 |
| 兼容性 | Windows 10 1809 及以上（x64） |

## 4. 界面规格（依据设计稿）
| 区域 | 规格 |
| --- | --- |
| 侧边栏 | 宽度 190px，主色 `#4C9A62` 渐变，顶部 Logo「我的工作台」，菜单项含图标+文字，选中项为浅绿胶囊高亮 `#66B37C` + 白色文字 |
| 内容区背景 | `#F3F7F3`（浅灰绿），卡片白色圆角 14px，阴影 `0 2px 10px rgba(31,84,49,.06)` |
| 主题色 | 默认「森林绿」：主绿 `#4C9A62`；辅助绿 `#E9F5EC`；进度黄 `#F5B942`；危险红 `#E86A5E`；文字主色 `#22322A`，次要 `#7C8B82`。另提供 5 套可切换主题（T-05），其中「暗夜黑」为深色模式 |
| 统计卡片 | 浅绿底 `#EAF6EE`，左侧圆形图标，数值加粗，右上角小标签 |
| 习惯进度环 | SVG 环形进度，中心显示 emoji 图标，下方显示 `已完成/目标` 与名称 |
| 优先级色标 | 高=红 `#E86A5E`，中=黄 `#F5B942`，低=绿 `#5CB878` |
| 字体 | `"Microsoft YaHei UI", "Segoe UI", sans-serif`；标题 600 字重 |

## 5. 数据需求（本地 SQLite）
数据库文件：`%APPDATA%/WorkHelper/workhelper.db`（WAL 模式）。核心表：`settings`、`schedules`、`todos`、`habits`、`habit_logs`、`priorities`、`modules`、`module_records`、`module_notes`、`news`、`reviews`、`focus_logs`。详见《数据库设计说明书》。

## 6. 验收标准
1. 界面与设计稿布局、配色、圆角卡片风格一致，窗口缩放时布局响应正常。
2. 2.2~2.9 全部功能可用，数据关闭应用后不丢失。
3. `npm run test` 单元测试全部通过；`npm run dist` 产出 NSIS 安装包，安装后可正常启动、卸载。
4. 无未捕获异常导致的白屏或崩溃。
