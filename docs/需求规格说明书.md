# 个人工作台（Workbench）功能规格说明书

| 项目名称 | 个人工作台 Workbench | 版本 | V1.0 |
| --- | --- | --- | --- |
| 文档类型 | 需求分析与功能规格说明书 | 编写日期 | 2026-10-08 |
| 适用平台 | Windows 10 / 11（x64） | 技术栈 | Electron + Vue 3 + TypeScript + SQLite |

## 1. 项目概述

### 1.1 项目背景
面向个人用户的日常效率管理工具。用户需要一个集「任务管理、日程安排、习惯打卡、心情记录、资产管理、本地阅读」于一体的桌面工作台，用于规划每一天的工作与生活，管理个人资金与攒钱目标，并在同一应用内阅读本地电子书。

### 1.2 设计目标
- 参照 `图片_20261008191001_27_69.jpg` 设计稿高度还原视觉效果（绿色主题、白色圆角卡片、进度环、双栏内容布局）。
- 全部功能离线可用，数据仅存储在本地，保障用户隐私。
- 冷启动时间 < 3 秒，常驻内存占用合理（< 300MB）。
- 支持 Windows 10 及以上操作系统。

### 1.3 术语定义
| 术语 | 说明 |
| --- | --- |
| 日程（Schedule） | 一天中的安排，时间可选（未设置时间时显示「全天」），支持颜色标记与固定到顶部 |
| 习惯（Habit） | 需要按天重复打卡的目标，如「多喝水 2 次/天」 |
| 生日（Birthday） | 自建的生日记录，支持公历或农历、提前提醒天数与备注 |
| 倒数日（Countdown） | 指向某个确定日期（含年）的一次性倒计时，到达后显示「已过 N 天」 |
| 纪念日（Anniversary） | 每年重复的日子（月/日），起始年份选填，填写后展示「第 N 周年」 |
| 资产账户（Asset Account） | 某个平台（支付宝/微信/银行等）下的资金账户，记录当前余额 |
| 攒钱计划 / 想买（Saving Goal） | 自定义目标金额与存钱周期（想买 = 目标商品），按存入明细实时展示进度 |
| 书籍（Book） | 导入到阅读模块的电子书（EPUB / PDF / TXT / Markdown），文件复制到数据目录 `books/` 子目录保存 |
| 阅读位置（Location） | 书内的定位：EPUB 为 CFI（精确定位到字符区间）、PDF 为页码、TXT / Markdown 为百分比 |
| 书签（Bookmark） | 用户标记的阅读位置，含展示名（章节名 / 页码 / 位置百分比）、百分比与记录时间 |
| 阅读设置（Reader Settings） | 阅读模块的排版偏好：字体、字号、行距、页边距与阅读配色主题 |

## 2. 功能需求

### 2.1 全局框架
| 编号 | 功能 | 说明 |
| --- | --- | --- |
| G-01 | 无边框窗口 | 自定义标题栏（最小化/最大化/关闭），支持拖拽移动、双击最大化；右上角常驻「设置」入口（齿轮按钮，当前处于设置页时高亮） |
| G-02 | 左侧导航栏 | 绿色主题侧边栏：首页 / 日历 / 功能广场三项固定显示（不可移除、不可移动：首页与日历恒置顶、功能广场恒排最后），其余功能按配置动态展示（见 F-01~F-03）且支持拖拽调整先后顺序，当前项高亮，支持滚动 |
| G-03 | 路由切换 | 页面切换无刷新，切换时保持数据实时性 |
| G-04 | 数据持久化 | 所有操作实时写入本地 SQLite 数据库 |

### 2.2 首页（仪表盘）
| 编号 | 功能 | 说明 |
| --- | --- | --- |
| H-01 | 问候卡片 | 根据当前时间动态问候（早上好/下午好/晚上好），显示当天日期、星期与一句鼓励语 |
| H-02 | 今日概览 | 今日日程完成 n/m、习惯打卡 n/m、今日进度百分比、今日状态（由完成率推导）；四张统计卡片整体可点击，点击跳转到「日历」查看统计看板 |
| H-03 | 今日日程清单 | 当日日程完整管理（原「每日计划」页已整合进首页，仅针对今天；其他日期通过日历右键添加与当日详情勾选）：单列清单，时间列（未设置时间显示「全天」）、标题与备注描述；排序规则：未完成在前 → 置顶日程优先 → 按时间升序（未设置时间排最后，按拖拽调整的手动顺序）→ 已完成沉底置灰；日程可带颜色标记（清单行左侧色条）；勾选完成动效：勾选标记弹跳（scale 0.72 → 1.12 → 1）、行背景渐变淡出、标题删除线自左向右渐进，取消完成反向恢复，遵循系统「减少动态效果」设置自动降级 |
| H-04 | 日程管理 | 清单顶部提供「＋ 添加」入口，直接打开日程表单；支持新增、编辑与删除（删除二次确认）；表单：时间可选（默认「全天」不设置时间，可切换「指定时间」）、颜色标记（默认 + 8 色）、备注描述；支持固定到顶部（图钉）与拖拽排序（未设置时间的日程可拖动，落点仅未设置时间的条目） |
| H-06 | 快捷入口 | 一键跳转「日历 / 资产 / 阅读」（展示侧边栏中的功能，固定功能始终包含） |
| H-07 | 生日提醒卡片 | 未来 60 天内有生日时展示临近生日列表（姓名、公历/农历、剩余天数），可跳转日历 |
| H-08 | 日期入口 | 右上角日期胶囊可点击，跳转到日历页 |
| H-09 | 心情打卡 | 首页「心情打卡」紧凑卡片（位于习惯打卡下方）：5 档心情横向排布，鼠标悬停预览（图标放大并弹出名称气泡）、点击即打卡并播放弹跳动画，卡片标题旁的心情图标随打卡结果切换（弹出 + 微旋转过渡）；未打卡时提示「今天还没打卡」，打卡后显示「已打卡 · 连续打卡 N 天」（从今天往前回溯统计连续记录天数）；再次点击当前档位表示取消记录；记录结果可在日历中回看与补记 |
| H-10 | 资产概览 | 资产功能加入侧边栏后展示：总资产、本月收入、本月支出；金额默认隐藏（¥****），点击眼睛图标切换显示；含「打开资产」跳转入口 |
| H-11 | 习惯打卡 | 首页右栏顶部「习惯打卡」面板（位于心情打卡上方）：进度环展示每个习惯「已完成/目标」，点击圆环 +1 快速打卡、达标发光，悬停可撤销一次；打卡次数不超过每日目标（达到目标后继续点击不再增长）；「管理」入口支持新增 / 编辑 / 删除习惯（名称、图标共 30 个候选、每日目标次数使用自绘步进器 1–20）；打卡后当日统计与进度实时联动 |

| C-11 | 数据看板 | 月视图与侧栏下方展示统计看板（原「每日计划」看板已整合进日历）：四张指标卡片（日程总数 / 已完成数 / 完成率 / 平均完成耗时）+ 完成率环形图（SVG）+ 近 7 天完成趋势迷你柱状图；指标随选中日期联动（环形图与完成率仅统计日程，平均完成耗时取已完成日程「创建时刻 → 完成时刻」的平均分钟数，四舍五入；缺少完成时刻的历史数据不参与统计，无有效样本时显示「—」） |

### 2.7 阅读
| 编号 | 功能 | 说明 |
| --- | --- | --- |
| B-01 | 书架管理 | 在功能广场添加「阅读」后进入书架：支持多选导入本地书籍（EPUB / PDF / TXT / Markdown，单本不超过 500MB），文件复制到数据目录 `books/` 子目录保存（导入后原文件可自由移动 / 删除）；EPUB 与 PDF 在导入后自动解析书名、作者并生成封面缩略图（解析失败保留文件名与默认封面）；书架以封面网格展示（封面 / 书名 / 作者 / 格式 / 大小 / 阅读进度），点击进入阅读，悬停显示移除按钮（二次确认，删除书籍文件与全部书签）；已读书籍按最近阅读时间排序 |
| B-02 | 文档解析 | EPUB：基于 epubjs 解析并按分页方式渲染（内嵌文档禁用脚本，杜绝恶意内容执行）；PDF：基于 pdf.js 逐页渲染为画布，随窗口宽度自适应缩放；TXT：自动识别 UTF-8 与 GBK 编码，按行分段展示；Markdown：渲染标题 / 列表 / 引用 / 代码块 / 表格，输出经 DOMPurify 净化，防止内联脚本与事件属性执行 |
| B-03 | 页面导航 | 上一页 / 下一页按钮，键盘 ← / → 与 PageUp / PageDown 翻页（输入控件聚焦时不拦截）；底部进度条可拖动跳转；实时展示当前位置（EPUB 为章节名或位置百分比，PDF 为「第 n / N 页」，TXT / Markdown 为「第 n / N 页」）；EPUB 提供章节目录面板，点击章节跳转；支持全屏沉浸阅读（工具栏按钮 / F11 切换系统全屏并隐藏应用侧边栏与顶栏，鼠标静止 3 秒后控制栏自动隐藏、移动鼠标恢复；再次按 F11 / Esc 或离开阅读页自动退出并还原窗口） |
| B-04 | 书签管理 | 工具栏「书签」面板可添加当前页书签（展示名取章节名 / 页码 / 位置百分比），列表按位置先后展示并显示百分比与记录时间，点击跳转到对应位置，支持单条删除；书签随书籍移除一并清理 |
| B-05 | 字体与阅读设置 | 设置面板支持字体（系统默认 / 宋体 / 楷体 / 黑体 / 仿宋）、字号（14–30）、行距（1.4–2.4）、页边距（24–96）与阅读配色（跟随应用 / 浅色 / 羊皮纸 / 夜间）调整，即时生效并持久化；「跟随应用」时配色随应用深浅色主题自动切换；PDF 为固定版式，仅背景配色生效并在面板中提示 |
| B-06 | 阅读进度 | 翻页 / 跳转后自动保存阅读位置与百分比（防抖落库），下次打开自动恢复到上次位置；按 Esc 关闭面板、返回书架时立即保存；书籍文件随「更改数据存储位置」一并迁移；JSON 备份包含书库元数据、封面与书签（书籍文件体积较大不随备份，需另行复制 `books/` 目录） |

## 5. 数据需求（本地 SQLite）
数据库文件：`%APPDATA%/Workbench/data/workbench.db`（WAL 模式）。核心表：`settings`、`schedules`、`habits`、`habit_logs`、`focus_logs`、`birthdays`、`moods`、`anniversaries`、`asset_accounts`、`asset_records`、`saving_goals`、`saving_deposits`、`books`、`bookmarks`（Schema 版本 user_version = 7，日程表含 `color` / `pinned` / `completed_at`；书籍文件存放于数据目录 `books/` 子目录，文件路径记录在 `books.file_name`）。`todos`、`priorities` 为历史保留表（对应功能已移除，仅保留历史数据，应用不再读写；备份导出不再包含）。详见《数据库设计说明书》。
