# 个人工作台 Workbench

一款面向个人的 Windows 桌面效率工具，集「日程安排、习惯打卡、心情记录、资产管理、本地阅读」于一体。界面参照设计稿实现（圆角卡片、进度环），内置 6 套主题可自由切换，全部功能离线可用，数据仅存储在本地 SQLite 数据库中。

## 功能概览

| 模块 | 说明 |
| --- | --- |
| 首页 | 今日概览（四张统计卡片可点击跳转「日历」数据看板）、问候卡片、今日日程完整管理（原「每日计划」页已整合：清单排序、时间可选、颜色标记、固定到顶部、拖拽排序、勾选完成动效、增删改与删除确认）、习惯打卡（进度环一键快速打卡与撤销，达到每日目标后不再增长）、紧凑版心情打卡（悬停预览 + 点击打卡 + 标题旁心情图标动画）、资产概览（默认隐藏金额）、快捷入口（随侧边栏配置联动） |
| 日历 | 月视图（公历 / 农历 / 节气 / 传统节日 / 法定节假日休/班角标、日程、生日、心情与倒数日/纪念日标记）、当日详情（农历干支、放假或调休、当日日程清单及完成状态、习惯打卡记录、当日完成率、心情记录）、右键日期弹出功能菜单（添加生日 / 添加日程 / 倒数日 / 纪念日）、生日管理、倒数日与纪念日管理、未来一周天气条、数据看板（选中日四张指标卡 + 完成率环形图 + 近 7 天完成趋势） |
| 天气 | 日历页展示未来一周天气（天气图标、中文描述、最低~最高温度），IP 自动定位城市，支持手动刷新，结果缓存 30 分钟，断网展示最近一次缓存；数据源 Open-Meteo（无需 API Key） |
| 心情打卡 | 首页紧凑版「心情打卡」：5 档心情横向排布，鼠标悬停预览（图标放大 + 名称气泡），点击即打卡并播放弹跳动画，卡片标题旁心情图标随打卡结果切换；显示打卡状态与连续打卡天数（未打卡时提示「今天还没打卡」，打卡后显示「已打卡 · 连续打卡 N 天」）；日历月视图显示每日心情表情，可回看、补记或取消记录 |
| 倒数日与纪念日 | 倒数日为一次性日期（到达后显示「已过 N 天」）；纪念日每年重复，起始年份选填（填写后显示「第 N 周年」，2 月 29 日平年回退 2 月 28 日）；日历右键菜单或侧栏管理卡添加，月视图以玫红圆点标记 |
| 资产 | 多平台账户（支付宝 / 微信支付 / 京东金融 / 云闪付 / 美团 / 抖音与 15 家银行等 23 个平台，品牌色徽章 + 真实 logo 图形）、收支记录（分类统计、余额自动联动）、资产分布饼图与近 30 天趋势、攒钱计划与「想买」（目标金额 + 存钱周期，实时进度，达标自动标记）；金额默认隐藏，点击眼睛显示 |
| 阅读 | 本地电子书阅读（EPUB / PDF / TXT / Markdown）：书架导入（文件复制入库、EPUB/PDF 自动解析书名作者封面）、继续阅读（进度自动保存恢复）、EPUB 目录跳转、翻页与进度条拖动（支持 ←/→、PageUp/PageDown 键盘翻页）、书签管理（添加 / 列表跳转 / 删除）、字体设置（系统默认 / 宋体 / 楷体 / 黑体 / 仿宋、字号、行距、页边距）与阅读配色（跟随应用 / 浅色 / 羊皮纸 / 夜间）、全屏沉浸阅读（按钮 / F11 切换系统全屏并隐藏应用框架，鼠标静止自动隐藏控制栏，Esc / F11 退出）；TXT 自动识别 UTF-8 与 GBK 编码，Markdown 渲染标题 / 列表 / 引用 / 代码 / 表格 |
| 功能广场 | 集中管理侧边栏功能：可配置功能（当前为「资产」「阅读」）以网格磁贴展示，图标使用独立色调与样式，支持添加、移除、拖拽调整顺序（在侧边栏中）与恢复默认，配置本地持久化（首页 / 日历 / 功能广场固定显示、设置位于右上角，均不在广场中管理） |
| 侧边栏自定义 | 首页 / 日历 / 功能广场固定显示（首页与日历置顶、功能广场恒排最后，不可移除、不可移动）；「资产」「阅读」可在功能广场添加，已添加项悬停可拖拽调整顺序（带插入指示线）或一键移除 |
| 外观主题 | 设置页内置 6 套配色（森林绿 / 海洋蓝 / 樱花粉 / 暖阳橙 / 紫罗兰 / 暗夜黑），点击即时全局换肤并自动持久化 |
| 设置 | 入口位于窗口右上角（齿轮按钮）：外观主题、昵称、数据导出备份、导入恢复、打开数据目录、更改数据存储位置、关于 |

## 技术栈

- **桌面框架**：Electron 44（无边框窗口 + 自定义标题栏）
- **界面**：Vue 3 + TypeScript + Pinia + Vue Router（Vite 构建）
- **数据**：SQLite（优先 better-sqlite3，自动回退 Node 内置 node:sqlite），WAL 模式
- **历法**：lunar-javascript 1.7.7（农历、干支、节气与法定节假日计算，主进程与渲染进程共用）
- **阅读**：epubjs 0.3.93（EPUB 解析与分页渲染，BSD-2-Clause）、pdfjs-dist 6（PDF 逐页渲染，Apache-2.0）、marked（Markdown 渲染）、DOMPurify（内容净化），均为 MIT 兼容许可证
- **测试**：Vitest + @vue/test-utils（176 个用例）
- **打包**：electron-builder（NSIS 安装包）

```
Workbench/
├── build/                  # 应用图标与 NSIS 安装脚本

│   │   ├── services/       # 领域服务（日程/习惯/统计/设置/天气/心情/生日/倒数日·纪念日/资产/攒钱/阅读/存储位置）
│   │   ├── ipc.ts          # IPC 处理器注册
│   │   └── index.ts        # 应用入口
│   ├── preload/            # 预加载脚本（contextBridge 白名单 API）
│   ├── renderer/           # 渲染进程（Vue 3 应用）
│   │   └── src/
│   │       ├── components/ # 通用组件（图标、弹窗、进度环、图表、阅读面板等）
│   │       ├── reader/     # 阅读引擎（EPUB / PDF / 文本，统一接口）
│   │       ├── router/     # 路由
│   │       ├── stores/     # Pinia 状态
│   │       ├── styles/     # 主题样式
│   │       └── views/      # 页面

```

## 开发与构建

```bash
# 安装依赖
npm install

# 启动开发模式（热更新）
npm run dev

# 类型检查
npm run typecheck

# 运行测试
npm test

# 构建生产包
npm run build

# 生成 Windows 安装包（NSIS）
npm run dist
```

打包产物位于 `dist/`，安装包名为 `Workbench-1.0.0-Setup.exe`。

## 数据存储

- 数据库文件：`%APPDATA%\Workbench\data\workbench.db`（WAL 模式）
- 书籍文件：复制到数据目录 `books/` 子目录（导入后原文件可自由移动 / 删除）
- 可在「设置 → 数据安全 → 更改位置」把数据迁到其他文件夹（复制数据库与书籍文件并热切换，原位置文件保留；目录配置存于 `userData/storage.json`）
- 支持通过环境变量 `WORKBENCH_DATA_DIR` 指定自定义数据目录（便携模式，优先级最高且禁用应用内更改）
- 应用内「设置 → 数据安全」支持 JSON 备份导出与恢复（含书库元数据、封面与书签；书籍文件体积较大不随 JSON 备份，需另行复制 `books/` 目录）
