# 个人工作台 WorkHelper

一款面向个人的 Windows 桌面效率工具，集「任务管理、日程安排、习惯打卡、笔记记录、数据统计」于一体。界面参照设计稿实现（圆角卡片、进度环），内置 6 套主题可自由切换，全部功能离线可用，数据仅存储在本地 SQLite 数据库中。

## 功能概览

| 模块 | 说明 |
| --- | --- |
| 首页 | 今日概览、问候卡片、日程与待办速览、近 7 天趋势、快捷入口（随侧边栏配置联动） |
| 每日计划 | 日期切换、四维统计卡片、今日日程、今日待办、习惯打卡（进度环）、重要事项（优先级色标）、下一个任务 + 专注计时 |
| 功能广场 | 集中管理侧边栏功能：分组展示全部功能，支持添加、移除与恢复默认，配置本地持久化 |
| 侧边栏自定义 | 侧边栏按配置动态生成；普通功能悬停可一键移除；首页 / 功能广场 / 设置为固定项 |
| 专注空间 | 番茄式专注计时（15/25/45/60 分钟），完成后记录时长，展示今日专注与最近记录 |
| 外观主题 | 设置页内置 6 套配色（森林绿 / 海洋蓝 / 樱花粉 / 暖阳橙 / 紫罗兰 / 暗夜黑），点击即时全局换肤并自动持久化 |
| 分类模块（9 个） | 减肥运动 / 英语学习 / 剪辑学习 / 播客精选 / 表达能力 / 读书推荐 / 妆容穿搭 / 爆款二创 / AI学习：模块目标、投入记录、模块笔记 |
| 新闻资讯 | 资讯录入、收藏、搜索、外链打开 |
| 工作复盘 | 每日复盘（今日完成 / 问题与反思 / 明日计划 / 心情） |
| 数据统计 | 关键指标、近 7 天任务趋势、习惯完成率、分类投入排行 |
| 设置 | 外观主题、昵称、数据导出备份、导入恢复、打开数据目录、关于 |

## 技术栈

- **桌面框架**：Electron 44（无边框窗口 + 自定义标题栏）
- **界面**：Vue 3 + TypeScript + Pinia + Vue Router（Vite 构建）
- **数据**：SQLite（优先 better-sqlite3，自动回退 Node 内置 node:sqlite），WAL 模式
- **测试**：Vitest + @vue/test-utils（61 个用例）
- **打包**：electron-builder（NSIS 安装包）

## 目录结构

```
WorkHelper/
├── build/                  # 应用图标与 NSIS 安装脚本
├── docs/                   # 项目文档（需求 / 架构 / 数据库 / 用户手册 / 测试报告）
├── scripts/                # 开发辅助脚本（环境自检、图标生成、演示数据）
├── src/
│   ├── main/               # 主进程：窗口、IPC、服务层、数据层
│   │   ├── db/             # 数据库连接、迁移、SQLite 适配层
│   │   ├── services/       # 领域服务（日程/待办/习惯/模块/资讯/复盘/统计/设置）
│   │   ├── ipc.ts          # IPC 处理器注册
│   │   └── index.ts        # 应用入口
│   ├── preload/            # 预加载脚本（contextBridge 白名单 API）
│   ├── renderer/           # 渲染进程（Vue 3 应用）
│   │   └── src/
│   │       ├── components/ # 通用组件（图标、弹窗、进度环、图表等）
│   │       ├── router/     # 路由
│   │       ├── stores/     # Pinia 状态
│   │       ├── styles/     # 主题样式
│   │       └── views/      # 页面
│   └── shared/             # 主/渲染进程共享类型、功能目录、主题目录与纯函数逻辑
└── tests/                  # 单元与集成测试
```

## 开发与构建

```bash
# 安装依赖
npm install

# 启动开发模式（热更新）
npm run dev

# 类型检查
npm run typecheck

# 运行测试
npm test

# 构建生产包
npm run build

# 生成 Windows 安装包（NSIS）
npm run dist
```

打包产物位于 `dist/`，安装包名为 `WorkHelper-1.0.0-Setup.exe`。

## 数据存储

- 数据库文件：`%APPDATA%\WorkHelper\data\workhelper.db`（WAL 模式）
- 支持通过环境变量 `WORKHELPER_DATA_DIR` 指定自定义数据目录（便携模式）
- 应用内「设置 → 数据安全」支持 JSON 备份导出与恢复
