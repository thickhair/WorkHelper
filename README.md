# 个人工作台 Workbench

一款面向个人的 Windows 桌面效率工具，集「任务管理、日程安排、习惯打卡、心情记录、资产管理」于一体。界面参照设计稿实现（圆角卡片、进度环），内置 6 套主题可自由切换，全部功能离线可用，数据仅存储在本地 SQLite 数据库中。

## 功能概览

| 模块 | 说明 |
| --- | --- |
| 首页 | 今日概览（四张统计卡片可点击跳转「每日计划」）、问候卡片、日程与待办速览、近 7 天趋势、资产概览（默认隐藏金额）、快捷入口（随侧边栏配置联动） |
| 每日计划 | 日期切换、四维统计卡片、今日日程、今日待办、习惯打卡（进度环）、重要事项（优先级色标）、下一个任务 + 专注计时 |
| 日历 | 月视图（公历 / 农历 / 节气 / 传统节日 / 法定节假日休/班角标、日程、生日、心情与倒数日/纪念日标记）、当日详情（农历干支、放假或调休、日程勾选、心情记录）、右键日期弹出功能菜单（添加生日 / 添加日程 / 倒数日 / 纪念日）、生日管理、倒数日与纪念日管理、未来一周天气条 |
| 天气 | 日历页展示未来一周天气（天气图标、中文描述、最低~最高温度），IP 自动定位城市，支持手动刷新，结果缓存 30 分钟，断网展示最近一次缓存；数据源 Open-Meteo（无需 API Key） |
| 心情打卡 | 首页「心情打卡」五档一键记录，显示打卡状态与连续打卡天数（未打卡时提示「今天还没打卡」，打卡后显示「已打卡 · 连续打卡 N 天」）；日历月视图显示每日心情表情，可回看、补记或取消记录 |
| 倒数日与纪念日 | 倒数日为一次性日期（到达后显示「已过 N 天」）；纪念日每年重复，起始年份选填（填写后显示「第 N 周年」，2 月 29 日平年回退 2 月 28 日）；日历右键菜单或侧栏管理卡添加，月视图以玫红圆点标记 |
| 资产 | 多平台账户（支付宝 / 微信支付 / 京东金融 / 各大银行 / 现金等 12 个平台，自绘品牌色图标）、收支记录（分类统计、余额自动联动）、资产分布饼图与近 30 天趋势、攒钱计划与「想买」（目标金额 + 存钱周期，实时进度，达标自动标记）；金额默认隐藏，点击眼睛显示 |
| 功能广场 | 集中管理侧边栏功能：可配置功能（当前为「资产」）以网格磁贴展示，图标使用独立色调与样式，支持添加、移除与恢复默认，配置本地持久化（首页 / 每日计划 / 日历 / 功能广场固定显示、设置位于右上角，均不在广场中管理） |
| 侧边栏自定义 | 首页 / 每日计划 / 日历 / 功能广场固定显示（置顶、不可移除）；「资产」可在功能广场添加，悬停菜单项可一键移除 |
| 外观主题 | 设置页内置 6 套配色（森林绿 / 海洋蓝 / 樱花粉 / 暖阳橙 / 紫罗兰 / 暗夜黑），点击即时全局换肤并自动持久化 |
| 设置 | 入口位于窗口右上角（齿轮按钮）：外观主题、昵称、数据导出备份、导入恢复、打开数据目录、更改数据存储位置、关于 |

## 技术栈

- **桌面框架**：Electron 44（无边框窗口 + 自定义标题栏）
- **界面**：Vue 3 + TypeScript + Pinia + Vue Router（Vite 构建）
- **数据**：SQLite（优先 better-sqlite3，自动回退 Node 内置 node:sqlite），WAL 模式
- **历法**：lunar-javascript 1.7.7（农历、干支、节气与法定节假日计算，主进程与渲染进程共用）
- **测试**：Vitest + @vue/test-utils（125 个用例）
- **打包**：electron-builder（NSIS 安装包）

## 目录结构

```
Workbench/
├── build/                  # 应用图标与 NSIS 安装脚本
├── docs/                   # 项目文档（需求 / 架构 / 数据库 / 用户手册 / 测试报告）
├── scripts/                # 开发辅助脚本（环境自检、图标生成、演示数据）

│   │   ├── services/       # 领域服务（日程/待办/习惯/统计/设置/天气/心情/生日/倒数日·纪念日/资产/攒钱/存储位置）
│   │   ├── ipc.ts          # IPC 处理器注册
│   │   └── index.ts        # 应用入口
│   ├── preload/            # 预加载脚本（contextBridge 白名单 API）
│   ├── renderer/           # 渲染进程（Vue 3 应用）
│   │   └── src/
│   │       ├── components/ # 通用组件（图标、弹窗、进度环、图表等）
│   │       ├── router/     # 路由
│   │       ├── stores/     # Pinia 状态
│   │       ├── styles/     # 主题样式
│   │       └── views/      # 页面
│   └── shared/             # 主/渲染进程共享类型、功能目录、主题目录与纯函数逻辑
└── tests/                  # 单元与集成测试
```

## 开发与构建

```bash
# 安装依赖
npm install

# 启动开发模式（热更新）
npm run dev

# 类型检查
npm run typecheck

# 运行测试
npm test

# 构建生产包
npm run build

# 生成 Windows 安装包（NSIS）
npm run dist
```

打包产物位于 `dist/`，安装包名为 `Workbench-1.0.0-Setup.exe`。

## 数据存储

- 数据库文件：`%APPDATA%\Workbench\data\workbench.db`（WAL 模式）
- 可在「设置 → 数据安全 → 更改位置」把数据迁到其他文件夹（复制数据库并热切换，原位置文件保留；目录配置存于 `userData/storage.json`）
- 支持通过环境变量 `WORKBENCH_DATA_DIR` 指定自定义数据目录（便携模式，优先级最高且禁用应用内更改）
- 应用内「设置 → 数据安全」支持 JSON 备份导出与恢复
